# 新手教學設計 — 課程留言管理

> 路由:`/admin/courses/[id]/comments` ｜ 對象:管理單一課程單元留言、回覆學員、處理檢舉的講師／管理員 ｜ 預估教學:約 35 秒(6 步)

## 1. 頁面核心用途
這頁是你跟學員留言的「對話台」:左邊挑一個單元、中間看那單元的所有留言、按「回覆」就能公開回大家看,或私下寄 email 給本人;不需要的留言也能在這裡刪掉。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 左側單元留言列表 | 一眼看哪些單元有留言,點一下就在中間打開那單元的留言 | 左側「留言總覽」清單 | ⭐ 必教 |
| 未讀紅點(點擊即已讀) | 紅色數字=還沒看的留言;點進該單元自動算已讀,不用手動標 | 單元名稱旁紅色數字、頂部「X 則未讀」 | ⭐ 必教 |
| 中央留言詳細列表 | 看到該單元每則留言的完整內容、留言時間、是誰留的 | 中央「單元留言管理」 | ⭐ 必教 |
| 匿名留言看得到本名 | 學員勾匿名,前台只顯示「學員」,但這裡會給你他的真名+信箱 | 留言上的「匿名」標籤與下方「真實身份」那行 | ⭐ 必教 |
| 回覆留言 | 按「回覆」寫內容,可公開回(大家看得到)或寄 email(只給他) | 每則留言右側「回覆」鈕 → 彈窗 | ⭐ 必教 |
| 發送方式二選一(可都選) | 勾「發送留言」公開回、勾「發送電子郵件」私下寄;至少勾一個才送得出去 | 回覆彈窗下方兩個勾選框 | ⭐ 必教 |
| 軟刪除留言 | 刪掉後前台看不到,但後台留紀錄;沒有還原鍵,刪了救不回 | 每則留言右側紅色「刪除」鈕 + 確認彈窗 | ⭐ 必教 |
| Word 式回覆編輯器 | 像打 Word 一樣加粗體、連結、清單寫回覆 | 回覆彈窗「回覆內容」欄 | ◐ 可帶過 |
| 信件標題自訂 | 寄 email 時改信件主旨;有預設可直接用 | 回覆彈窗「信件標題」欄(勾 email 才出現) | ◐ 可帶過 |
| 關鍵字一鍵帶入 | 點「複製」貼上 `{{用戶名稱}}` 等,系統自動代入學員真實內容 | 回覆彈窗右側「可用關鍵字」 | ◐ 可帶過 |
| 留言統計 | 看這課程總共幾則、幾則未讀 | 左側「留言總覽」上方、中央標題 | ◐ 可帶過 |
| 全課程留言表格 | 在上方「留言」分頁跨課程掃所有留言、直接回或刪 | 「留言」分頁頂部篩選 + 表格 | ✕ 不教 |
| 無限滾動載入更多 | 表格往下滑自動載入更多留言 | 全留言表格「載入更多」 | ✕ 不教 |
| 快速連到課程內容 | 表格內課程／章節／單元可點擊跳轉 | 全留言表格各欄連結 | ✕ 不教 |
| 手動重新整理 | 點「重新整理」或「更新」手動刷新列表 | 左側頂部、中央右上角 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點
- **回覆預設是「只寄 email」,不是公開回。** 打開回覆彈窗時,系統預設勾的是「發送電子郵件」、沒勾「發送留言」。想讓全班看到你的回覆,要自己補勾「發送留言」。
- **回匿名留言,小心洩漏本名。** 你看得到本名,但學員選了匿名。如果你勾「發送留言」公開回,內容裡別直接打他的名字;用 `{{用戶名稱}}` 關鍵字讓系統處理最安全。
- **刪除救不回來。** 刪掉只是前台隱藏,沒有「還原」鍵,誤刪要找工程師;已刪的留言也不能再回覆。
- **兩個發送框都不勾,送不出去。** 「發送回覆」按鈕會變灰,至少勾一個。
- **這裡只管公開留言。** 學員的「私訊老師」已搬到上方「私訊」分頁,不在這頁。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這頁是你跟學員留言的對話台:左邊挑單元、中間看留言、按回覆就能公開回或私下寄信。30 秒帶你走一遍。」

**逐步引導:**

1. **【先從左邊挑單元】** — 特寫元素:`data-tour="comment-lesson-list"`
   - 文案:「留言分單元放。先在左邊點一個單元,中間才會出現留言。」
   - 為何教:整頁是「先選單元才有內容」的設計,沒先點就只看到空白,這是第一個卡點。

2. **【紅點 = 有人剛留言】** — 特寫元素:`data-tour="comment-unread-badge"`
   - 文案:「紅色數字是還沒看的留言。點進去就自動算已讀。」
   - 為何教:未讀是講師每天進來第一眼資訊,且「點擊即已讀」是看不見的行為,要講明。

3. **【中間看完整留言】** — 特寫元素:`data-tour="comment-detail-list"`
   - 文案:「這裡是該單元所有留言,內容、時間、誰留的都在。」
   - 為何教:這是主要工作區,讓講師知道完整內容在中間,不是左邊的摘要。

4. **【匿名留言你看得到本名】** — 特寫元素:`data-tour="comment-real-identity"`
   - 文案:「學員勾匿名,前台只寫「學員」,但這行會給你他的真名跟信箱。」
   - 為何教:匿名揭示是這頁獨有、最容易誤會的設計,也牽涉回覆別洩漏身份。

5. **【按回覆:公開回或私下寄信】** — 特寫元素:`data-tour="comment-reply-button"`
   - 文案:「按回覆寫內容。預設只寄 email 給他;想全班看到,要自己勾「發送留言」。至少勾一個才送得出。」
   - 為何教:回覆是核心動作。「預設只寄 email」「兩個都不勾按鈕鎖住」是兩大誤區。彈窗內的 Word 式編輯器與 `{{用戶名稱}}` 關鍵字一句帶過即可,回匿名留言用關鍵字才不洩漏本名。

6. **【刪除是軟刪除,救不回來】** — 特寫元素:`data-tour="comment-delete-button"`
   - 文案:「刪掉後前台看不到,但沒有還原鍵,誤刪要找工程師。已刪的不能再回。」
   - 為何教:不可逆是高風險點,務必先提醒再讓他動手。

**可中斷 / 備註:**
- **最大段落分界在第 1 步之後**:前 1–3 步講「怎麼找留言」,第 4 步起才進「怎麼處理」。中途離開可在這裡自然收尾。
- **最小必走路徑 = 第 1 步 + 第 5 步**(選單元 + 回覆)。使用者趕時間時只保留這兩步,其餘標為可選。
- **第 6 步(軟刪除不可逆)即使被跳過,也建議至少曝光一次警告**,避免誤刪救不回。
- 第 5 步彈窗內的編輯器、信件標題、關鍵字皆為可帶過,已併進該步一句話;使用者實際點開彈窗才需展開,否則略過不影響主流程。
- 右側「提示」欄、全課程留言表格、無限滾動、重新整理等為不教項,不納入導覽。
