# 新手教學設計 — 優惠券管理

> 路由:`/admin/coupons` ｜ 對象:想用折扣碼做促銷的講師 ｜ 預估教學:約 40 秒(5 步)

## 1. 頁面核心用途

讓你建立、管理折扣碼,用優惠價推課程或組合包。這頁是所有優惠券的總覽,看得到每張券賣得如何、還能不能用。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 新增優惠券 | 進入表單建立一張新券 | 右上「新增優惠券」按鈕 | ⭐ 必教 |
| 複製優惠碼 | 點代碼一鍵複製,貼給學員 | 表格「代碼」欄 | ⭐ 必教 |
| 查看折扣內容 | 看每張券折多少(金額 / 百分比 / 上限) | 表格「折扣」欄 | ◐ 可帶過 |
| 查看適用範圍 | 看是全站還是限定課程 / 組合包 | 表格「適用範圍」欄 | ◐ 可帶過 |
| 查看使用次數 | 看已用幾次 / 上限多少 | 表格「已使用 / 上限」欄 | ◐ 可帶過 |
| 看券的狀態 | 啟用中 / 已停用 / 已過期 / 未開始 | 表格「狀態」欄 | ⭐ 必教 |
| 看有效期間 | 生效到到期的日期區間 | 表格「有效期間」欄 | ✕ 不教 |
| 快速啟用 / 停用 | 用開關即時關掉或打開一張券 | 表格右側 Switch | ⭐ 必教 |
| 編輯優惠券 | 進入表單修改設定 | 表格右側鉛筆圖示 | ◐ 可帶過 |
| (表單)折扣設定 | 設固定金額或百分比、折扣上限 | `/admin/coupons/new` 表單 | ✕ 不教(另頁) |
| (表單)使用限制 | 總兌換上限、每人上限、最低消費、限首購 | 同上 | ✕ 不教(另頁) |
| (表單)適用範圍 | 全站 / 指定課程 / 指定組合包 | 同上 | ✕ 不教(另頁) |
| (表單)時間與狀態 | 生效 / 到期時間、啟用開關 | 同上 | ✕ 不教(另頁) |

### 容易誤解 / 客戶常漏的點

- 「狀態」是系統算出來的綜合結果:就算開著(active),只要過了到期時間就會顯示「已過期」,學員一樣不能用。
- 右側那個開關是「臨時關閉」用的,不用進去編輯就能立刻停掉一張券。
- 優惠碼建立後不能改;要換碼只能停用舊的、開一張新的。
- 「全站」代表所有課程和組合包都能用,沒勾任何商品就是全站。

## 3. 新手教學流程

**開場白**:
> 「想做檔期促銷、發折扣碼給學員?這頁就是你的優惠券總管。我帶你 40 秒看懂怎麼開券、複製碼、跟一鍵開關。」

**逐步引導:**

1. **【開一張新券】** — 特寫:`coupons-new-btn` — 文案:「要做促銷?點這裡開新券。下一頁設折多少、限哪些課、能用多久。」— 為何教:這是建立優惠券的唯一入口,新手第一步。
2. **【你的券都在這張表】** — 特寫:`coupons-table` — 文案:「所有優惠券列在這。折多少、用幾次、還能不能用,一眼掃過去。」— 為何教:建立整頁的心智地圖。
3. **【點代碼就複製】** — 特寫:`coupons-code-col` — 文案:「點任一張券的代碼,直接複製。貼到貼文或私訊發給學員就行。」— 為何教:這是日常最高頻動作,但「點代碼=複製」不直覺。
4. **【狀態看券能不能用】** — 特寫:`coupons-status-col` — 文案:「這欄是系統判定。就算開著,過期或還沒到生效時間,學員一樣用不了。」— 為何教:狀態是綜合結果,最容易誤會。
5. **【一鍵開關不用進編輯】** — 特寫:`coupons-actions-col` — 文案:「右邊開關能立刻停掉一張券,不用進去改;鉛筆才是進去編輯。」— 為何教:區分「快速停用」與「編輯」,避免不必要的點擊。

**可中斷 / 備註:**

- 第 2~5 步聚焦的是表格與欄位,只有「已有至少一張券」時才會出現;空狀態下框架會自動略過找不到的錨點,留下第 1 步即可。
- 折扣金額、使用限制、適用範圍等細節都在另一個路由的表單頁(`/admin/coupons/new`),不在本頁教,避免一次塞太多。
