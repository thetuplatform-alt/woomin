# 新手教學設計 — 金流收款

> 路由:`/admin/payments` ｜ 對象:要設定線上收款方式與臺灣電子發票的講師/管理員(僅 ADMIN) ｜ 預估教學:約 35 秒(4 步)

## 1. 頁面核心用途

這頁讓你設定「怎麼收學員的錢」(金流閘道)以及「要不要開統一發票」。兩件事各自獨立——用哪家收款,跟用哪家開發票互不影響。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 兩大分頁切換 | 在「金流收款」與「臺灣統一發票」兩塊設定間切換 | 頁面上方分頁列 | ⭐ 必教 |
| 選金流閘道 | 三擇一:SHOPLINE / Stripe / PAYUNi | 收款分頁,閘道卡片 | ⭐ 必教 |
| 填金流憑證 | 商店代號、API Key、沙盒切換、Webhook URL | 收款分頁,選定閘道後出現的設定卡 | ◐ 可帶過 |
| 測試金流連線 | 按鈕驗證憑證是否正確 | 收款分頁,設定卡底部 | ◐ 可帶過 |
| 開啟電子發票 | 用開關決定要不要串接電子發票 | 發票分頁,最上方啟用卡 | ⭐ 必教 |
| 選發票加值中心 | 二擇一:綠界 ECPay / 藍新 ezPay | 發票分頁,啟用後出現 | ◐ 可帶過 |
| 填發票憑證與賣方資訊 | 商店代號、HashKey/IV、賣方抬頭、統編 | 發票分頁,啟用後出現 | ✕ 不教(藏在啟用後) |
| 自動開立 / 測試開立 | 勾選付款後自動開票、按鈕試開一張 | 發票分頁,設定卡 | ◐ 可帶過 |
| 儲存設定 | 底部浮動儲存列,改動後出現 | 頁面底部 | ✕ 不教(改了自然會看到) |

### 容易誤解 / 客戶常漏的點

- **收款和發票是兩回事**:很多人以為選了金流就會自動開發票,其實要另外去發票分頁啟用。
- **個人開不了統一發票**:必須是有統編的營業人才能開,個人賣家請先別啟用發票。
- **測試模式 vs 正式模式**:正式模式下按「測試開立」會開出一張真發票,別亂按。
- **發票設定藏在開關後面**:沒打開啟用開關,下面的供應商與憑證欄位不會出現。

## 3. 新手教學流程

**開場白**:
> 「收學員的錢,就在這頁設定。我帶你 35 秒看懂:選哪家收款、要不要開發票,兩件事分開設,不會搞混。」

**逐步引導:**

1. **【先選怎麼收款】** — 特寫:`payments-tab-collection` — 文案:「這塊是收款設定。先選一家金流:SHOPLINE、Stripe 或 PAYUNi,三擇一。」— 為何教:這是這頁的主功能,讓使用者先定位收款分頁。
2. **【填好憑證、測一下】** — 特寫:`payments-tab-collection` — 文案:「選好後填商店代號、金鑰,底部有『測試連線』可先驗對不對。」— 為何教:讓使用者知道憑證欄位與測試按鈕在選定閘道後會出現,降低卡關。
3. **【要開發票?切到這裡】** — 特寫:`payments-tab-einvoice` — 文案:「想開統一發票?切到這分頁。收款和發票分開設,互不影響。」— 為何教:破除「選了金流就會自動開發票」的誤解。
4. **【打開開關才會出現設定】** — 特寫:`payments-einvoice-enable` — 文案:「先打開這個開關,下面才會跳出供應商和憑證欄位。注意:要有統編才能開發票。」— 為何教:發票憑證藏在啟用開關後,且個人不能開票,這是最常踩的雷。

**可中斷 / 備註:**

- 第 2 步特寫對齊收款分頁觸發點,因為金流憑證欄位要選定閘道後才出現,不是常駐 DOM,故錨定到常駐的分頁標籤。
- 第 4 步只錨定「啟用卡」,因為供應商選擇、憑證輸入、測試開立等只有打開開關後才渲染,框架會自動略過找不到的錨點,故不替它們建錨點。
- 金流閘道卡片本身位於共用元件 `payment-settings-form.tsx`(同時被 `/admin/settings/payment` 使用),不在本頁負責範圍內,故不於該檔加錨點,改以收款分頁標籤承載前兩步文案。
