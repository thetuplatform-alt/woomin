# 新手教學設計 — 課程列表

> 路由:`/admin/courses` ｜ 對象:講師 / 管理員(每次進後台管理課程的起點) ｜ 預估教學:約 40 秒(5 步)

## 1. 頁面核心用途

這裡是你所有課程的總管中心 — 一眼看出哪些還是草稿、哪些已經上架在賣,也是你開新課、找課、改課的起點。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 建立新課程 | 點「新增課程」開一門全新的課,先存成草稿 | 右上角綠色按鈕(加號) | ⭐ 必教 |
| 查看課程列表 | 一張表看完所有課:封面、標題、狀態、賣法、價格、日期 | 頁面中央表格 | ⭐ 必教 |
| 看「狀態」標籤 | 一眼分辨草稿(灰)、已發佈(綠)、隱藏(淺) | 表格「狀態」欄 | ⭐ 必教 |
| 看「可見性」標籤 | 一眼分辨賣法:公開(綠)、連結(藍)、邀請(黃) | 表格「可見性」欄 | ⭐ 必教 |
| 看標題與副標題 | 看到課名;沒指定講師時標題旁有黃色「全講師共管」 | 表格「標題」欄 | ⭐ 必教 |
| 看課程價格 | 看到原價、促銷價(刪除線)、免費 / 永久免費 | 表格「價格」欄 | ⭐ 必教 |
| 點列進編輯 | 點整行任一處,進該課的編輯頁 | 整行可點 | ⭐ 必教 |
| 編輯課程 | 點鉛筆圖示進編輯(等同點整行) | 表格最右欄 | ⭐ 必教 |
| 按狀態篩選 | 下拉只看草稿 / 已發佈 / 隱藏 | 表格上方「狀態」下拉 | ⭐ 必教 |
| 按可見性篩選 | 下拉只看公開 / 連結 / 邀請 | 表格上方「可見性」下拉 | ⭐ 必教 |
| 按名稱搜尋 | 打關鍵字找課(同時查標題與副標題) | 表格上方搜尋框 | ⭐ 必教 |
| 空狀態提示 | 還沒有課時,提示去點「新增課程」開第一門 | 表格區域 | ⭐ 必教 |
| 清除所有篩選 | 點 X 一鍵清掉搜尋與篩選 | 篩選列右側 X | ◐ 可帶過 |
| 刪除課程 | 點紅色垃圾桶,確認後永久刪除 | 表格最右欄 | ◐ 可帶過 |
| 看封面縮圖 | 用封面快速認出課程 | 表格「封面」欄 | ◐ 可帶過 |
| 看建立日期 | 看到每門課的建立日期 | 表格「建立日期」欄 | ◐ 可帶過 |
| 分頁瀏覽 | 超過 10 門課時翻頁查看 | 表格下方分頁列 | ◐ 可帶過 |
| 看課程計數 | 看「顯示 X-Y 筆,共 Z 筆」 | 分頁列左側 | ◐ 可帶過 |
| 載入狀態 | 資料載入時看到轉圈圖示 | 表格區域 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點

- **「狀態」和「可見性」是兩件事,最容易搞混。** 狀態=學生看不看得到(草稿就藏起來);可見性=怎麼賣(公開逛得到 / 靠連結 / 靠邀請碼)。**兩個都要設對課程才算完整上架。**
- **草稿永遠不會出現在前台。** 就算可見性設成「公開販售」,只要狀態還是草稿,學生就是看不到。改成「已發佈」才會出現。
- **刪除救不回來。** 紅色垃圾桶是永久刪除,沒有回收站,刪前再確認一次。
- **「免費」可能有兩種。** 顯示「永久免費」=有開循環促銷;只顯示「免費」=促銷價設 0 但沒開循環。要確認得進編輯頁看定價。
- **「全講師共管」標籤** 代表這門課沒指定講師,所有講師都能改。多人協作時記得確認有沒有指定到人。
- **改搜尋或篩選時,頁碼會自動跳回第 1 頁**,這是正常的,避免停在不存在的頁。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這是你的課程總管中心 — 哪些是草稿、哪些已上架,一眼看清楚。我帶你 40 秒學會開課、找課、改課。」

**逐步引導:**

1. **【從這裡開一門新課】** — 特寫元素:`data-tour="new-course-btn"`
   - 文案:「想開新課?點這裡。新課先存成草稿,學生還看不到,慢慢改沒關係。」
   - 為何教:這是建課的唯一入口,新手第一件事就是開第一門課;順手帶出「草稿」概念,為下一步鋪路。

2. **【你的課都在這張表】** — 特寫元素:`data-tour="course-table"`
   - 文案:「所有課列在這。封面、價格、賣法一眼掃過去。黃色『全講師共管』代表還沒指定講師。」
   - 為何教:建立整頁的心智地圖,知道每一欄在看什麼;共管標籤順帶一句,不另開步驟。

3. **【「狀態」決定學生看不看得到】** — 特寫元素:`data-tour="status-column"`
   - 文案:「草稿=只有你看得到,已發佈=學生才買得到。卡在草稿,做再多都不會上架。」
   - 為何教:最高頻的踩雷點 — 課做好了卻沒人看到,通常就是還停在草稿,必須講清楚。

4. **【「可見性」決定怎麼賣】** — 特寫元素:`data-tour="visibility-column"`
   - 文案:「這欄是賣法,跟上面是兩回事。公開=逛得到,連結=只能用網址買,邀請=要邀請碼。」
   - 為何教:新手最常把狀態和可見性搞混;緊接上一步對比,一次釘死兩個概念。

5. **【找課 + 進去改】** — 特寫元素:`data-tour="course-filters"` 與 `data-tour="row-actions"`
   - 文案:「課多了,打字搜或用下拉篩;點整行就能進去改。紅色垃圾桶是刪除 — 刪了救不回,手別抖。」
   - 為何教:搜尋 / 篩選與進編輯都是核心動作,操作直覺可合併講;順手帶出刪除不可復原的警告收尾。

**可中斷 / 備註:**

- 全程唯讀,不會替使用者建課、篩選或刪除;任何一步結束都可隨時關閉,不影響頁面。
- 自然中斷點:**第 1 步後**(已學會建課)、**第 4 步後**(已搞懂狀態 vs 可見性)— 這兩處各自是完整小目標,提前離開也拿到了最關鍵知識。
- 中途跳過直接關閉即可,毋需復原任何 UI;再次點問號從第 1 步重新開始,不保留進度。
- 第 3、4 步是本頁靈魂;若要精簡版,只留 1、3、4、5 即可成立。
- 空狀態(還沒有任何課)時,第 2~4 步的表格錨點不存在,自動跳過,只留第 1 步建課引導,呼應頁面本身的空狀態提示。
