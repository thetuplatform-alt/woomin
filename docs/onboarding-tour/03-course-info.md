# 新手教學設計 — 課程資訊（含歡迎信）

> 路由：`/admin/courses/[id]/info` ｜ 對象：要設定課程基本資料、封面、上架狀態、防翻拍與購買後歡迎信的講師 ｜ 預估教學:約 70 秒（7 步）

## 1. 頁面核心用途
這頁是課程上線前的「身分證」：填好課程名字和網址、決定要不要公開上架、設好防翻拍，還有設定學員買完後自動收到的歡迎信。設定完記得按儲存。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 基本資訊 | 填課程標題（必填）、副標題、網址識別碼 Slug（必填）、課程描述 | 左側「基本資訊」 | ⭐ 必教 |
| 封面圖片 | 上傳、預覽、更換或移除課程封面（10MB 內），也會當作社群分享圖 | 左側「封面圖片」 | ⭐ 必教 |
| 管理權限 | 勾選哪些講師能編這堂課；沒勾＝全部講師都能管 | 左側「管理權限」 | ⭐ 必教 |
| 講師資訊 | 填講師名稱、職稱、簡介，會顯示在課程頁 | 左側「講師資訊」 | ◐ 可帶過 |
| 課程狀態 | 選草稿／已發佈／隱藏，控制要不要上架 | 左側「課程狀態」 | ⭐ 必教 |
| 販售可見性 | 選公開販售／連結販售／私密邀請，控制誰看得到購買按鈕 | 「課程狀態」下方 | ⭐ 必教 |
| SEO 設定 | 填搜尋引擎看到的標題、描述、關鍵字 | 左側「SEO 設定」 | ◐ 可帶過 |
| OG / 社群分享 | 設定分享到 FB／LINE 時顯示的標題、描述、圖片 | 左側「OG / Social」 | ◐ 可帶過 |
| 銷售頁設定 | 複製指令請 AI 幫你做專屬銷售頁 | 左側「銷售頁設定」 | ✕ 不教 |
| 影片防翻拍浮水印 | 播放時疊上會移動的學員 Email 浮水印，防翻拍外流 | 左側「影片浮水印」 | ◐ 可帶過 |
| 購買成功通知 | 開啟後每筆購買自動寄信通知管理員 | 「通知設定」 | ◐ 可帶過 |
| 歡迎信設定（另一頁） | 點進去設定學員買完自動收到的歡迎信 | 「通知設定」內連結 | ◐ 可帶過 |
| └ 歡迎信開關 | 控制要不要自動寄；預設是關的 | 歡迎信頁最上方 | ⭐ 必教 |
| └ 歡迎信標題與內容 | 寫信件標題與內容，可塞 {{學員名稱}} 等變數 | 歡迎信頁「內容模板」 | ⭐ 必教 |
| └ 可用變數清單 | 一鍵複製變數插入信件 | 歡迎信頁右側 | ⭐ 必教 |
| └ 預覽與寄測試信 | 先看排版、寄一封到自己信箱確認 | 歡迎信頁「預覽與測試」 | ◐ 可帶過 |
| 左側快速導覽 | 點標籤直接跳到對應區段 | 頁面左側固定導覽列 | ◐ 可帶過 |
| 儲存列 | 一有改動就浮出「儲存」按鈕，按下才存檔 | 頁面下方 | ⭐ 必教 |
| 即時錯誤提示 | 欄位填錯時下方顯示紅字提醒 | 各欄位下方 | ⭐ 必教 |

### 容易誤解 / 客戶常漏的點
- **Slug（網址）一設就難改**：新手常隨便填，之後想換課程網址會很麻煩。
- **存了檔不等於上架**：狀態停在「草稿」就不會上線，要改成「已發佈」才真的公開。
- **「狀態」和「販售可見性」是兩回事**：一個管課程上不上線，一個管誰看得到購買按鈕，最容易搞混。
- **管理權限「沒勾人＝全開放」**：想鎖權限卻忘了勾講師，反而開放給所有講師。
- **歡迎信預設是關的**：信寫得再好，沒開開關學員一樣收不到。
- **變數名稱要寫對**：要用 {{course_url}} 這種系統認得的寫法，寫錯學員會看到原始文字。
- **沒設社群圖會自動用封面**：OG 圖建議 1200×630，比例差太多分享時會被裁切。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這頁是課程上線前的『身分證』——填好名字網址、決定要不要上架、設好防翻拍跟購買後的歡迎信。我帶你走最關鍵的幾步，大概一分鐘，想自己看隨時可以關掉。」

**逐步引導:**

1. **【先填標題和網址】** — 特寫元素：`data-section="basic-info"`（建議在 Slug 欄位加 `data-tour="basic-info-slug"`）
   - 文案：「標題必填。下面的網址（Slug）只能用小寫英數和連字號，像 react-basics，上線後很難改，想清楚再填。」
   - 為何教：Slug 是最容易踩的雷，新手隨便填之後改網址會卡住。

2. **【上傳一張封面】** — 特寫元素：`data-section="cover-image"`（建議卡片加 `data-tour="cover-image"`）
   - 文案：「傳一張封面，10MB 以內，會出現在課程列表。沒另外設社群圖時，分享出去也用這張。」
   - 為何教：封面必設，一張圖同時餵列表和社群分享，一次講完最省事。

3. **【設定誰能管這堂課】** — 特寫元素：`data-section="instructor-access"`（建議在右上 Badge 加 `data-tour="instructor-access-badge"`）
   - 文案：「沒勾任何人時，所有講師都能管（會顯示『全部講師』）。想限制就勾出特定的人。」
   - 為何教：「不勾＝全開放」很反直覺，新手想鎖權限卻忘了勾。

4. **【上架要選「已發佈」】** — 特寫元素：`data-section="status"`（建議卡片加 `data-tour="status-selects"`）
   - 文案：「上面『狀態』選已發佈才會真的上線，留在草稿不會公開。下面『販售可見性』是另一回事，管的是誰看得到購買按鈕。」
   - 為何教：最常見的致命錯——存了檔卻忘了改成已發佈，課程永遠不上線。

5. **【想防翻拍就開浮水印】** *(選用)* — 特寫元素：`data-section="video-watermark"`（建議在開關加 `data-tour="watermark-toggle"`）
   - 文案：「打開這個開關，影片上會浮現會移動的學員 Email 浮水印。透明度、移動方式都能調，右邊有即時預覽。」
   - 為何教：賣課很在意防翻拍，但屬加值功能，一步順帶帶過、不展開細項。

6. **【設購買後的歡迎信】** *(選用)* — 特寫元素：`data-section="notifications"` 內的歡迎信連結（建議加 `data-tour="welcome-email-link"`）
   - 文案：「點『歡迎信設定』會跳到另一頁，寫學員買完自動收到的信。記住：那頁的寄送開關預設是關的，沒開再會編都不會寄。」
   - 為何教：歡迎信是學員第一印象，「忘了開開關」是最常見的白工，必須先警告。

7. **【改完記得按儲存】** — 特寫元素：頁面下方 StickySaveBar（建議加 `data-tour="sticky-save-bar"`）
   - 文案：「有任何改動，下方就會冒出儲存列。按下去才會存檔，填錯的欄位會在下方標紅。改完別忘了存。」
   - 為何教：再好的設定沒按儲存都是白做，順便點出紅字提示收尾。

**可中斷 / 備註:**
- **每張卡片各自獨立**，任一步結束都可安全關閉，設定不會半套。
- **建議在第 4 步後設「核心已講完」軟分段**：前 4 步是上架前必做，後 3 步（浮水印、歡迎信、儲存）偏加值，趕時間的人看完前段即可。
- **第 5 步浮水印可整步略過**，不影響課程上線。
- **第 6 步歡迎信會跳到 `/admin/courses/[id]/welcome-email` 獨立頁**；若導覽不支援跨頁，改用「之後到通知設定點進去設」帶過，不要強制導頁。
- **第 7 步儲存是全頁共用**，即使中途跳出也要提醒「離開前先存」。
- **標記現況**：程式碼目前用 `data-section`（如 `basic-info`、`cover-image`、`status`、`video-watermark`、`notifications`），尚無 `data-tour`。導入導覽時可直接複用既有 `data-section` 當錨點，或補上述建議標記。
