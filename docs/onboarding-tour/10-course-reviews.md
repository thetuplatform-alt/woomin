# 新手教學設計 — 課程評價管理

> 路由:`/admin/courses/[id]/reviews` ｜ 對象:管理課程口碑的講師(看星評、回覆、處理檢舉) ｜ 預估教學:約 40 秒(6 步)

## 1. 頁面核心用途

這頁讓你管理一門課的口碑:看學員打幾分、親自回覆評價、把不當評價藏起來,並決定要不要在銷售頁秀出評價當社會證明。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 啟用評價功能 | 控制學員能不能寫新評價;關掉後舊評價還在但入口全消失 | 頁面最上方設定卡第一個開關 | ⭐ 必教 |
| 在銷售頁顯示評價 | 控制評價區塊要不要出現在課程銷售頁 | 啟用評價後才出現的第二個開關 | ⭐ 必教 |
| 查看評價統計 | 一眼看平均分、總則數、各星等人數 | 設定卡下方三張統計卡 | ⭐ 必教 |
| 隱藏/顯示單則評價 | 把垃圾或不實評價藏起來,學員看不到但後台留底 | 每則評價右上角的眼睛圖示 | ⭐ 必教 |
| 查看舉報原因 | 看評價被學員檢舉的原因和日期 | 學員名字旁的紅色「N 舉報」標 | ⭐ 必教 |
| 回覆評價 | 在後台回覆學員,回覆會同步顯示在銷售頁 | 每則評價下方的回覆框 | ⭐ 必教 |
| 查看評價內容與學員資訊 | 看星級、文字、頭像名字、日期、幾人覺得有用 | 評價卡片主區域 | ⭐ 必教 |
| 編輯回覆 | 修正回覆的錯字或內容 | 回覆內容右側的鉛筆圖示 | ◐ 可帶過 |
| 刪除回覆 | 移除你對某則評價的回覆 | 回覆內容右側的垃圾桶圖示 | ◐ 可帶過 |
| 按星等篩選評價 | 只看特定星級(如只看 1 星)的評價 | 評價列表右上的「篩選星等」下拉 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點

- **總開關連鎖反應**:關掉「啟用評價功能」會自動連帶關掉「銷售頁顯示」;重新打開時會恢復你之前的設定,不用重設。
- **隱藏不等於刪除**:藏起來的評價後台還看得到(變淡色 +「已隱藏」標),只是學員看不到,且仍計入統計。
- **統計含全部評價**:平均分、則數、星等分佈都算進隱藏的評價,也不受篩選星等影響。
- **回覆會同步銷售頁**:這裡寫的、改的、刪的回覆,銷售頁該則評價底下會即時跟著變。
- **舉報只能看不能清**:看得到舉報原因,但無法清除紀錄;真有問題就用眼睛圖示藏掉。
- **紅色舉報標只在被檢舉時出現**,沒被舉報的評價不會有,容易漏看。
- **列表固定最新在上**,頁面上不能改排序。

## 3. 新手教學流程

**開場白**(點問號後第一句):

> 「這頁是你管課程口碑的地方:看學員打幾分、回覆他們、把不當評價藏起來,還能決定要不要在銷售頁秀評價。30 秒帶你走一遍。」

**逐步引導:**

1. **【先決定要不要收評價】** — 特寫元素:`data-tour="enable-reviews-switch"`
   - 文案:「這開關控制學員能不能寫評價。關掉,舊評價還在、入口全消失。」
   - 為何教:整頁總開關,連鎖影響下面設定,必須最先講。(若此開關是關的,文案補一句「打開後下方會多一個銷售頁顯示開關」並併入下一步)

2. **【再決定銷售頁要不要秀】** — 特寫元素:`data-tour="show-reviews-switch"`
   - 文案:「打開,評價就出現在銷售頁當好評背書。只在上面開關開著時才看得到。」
   - 為何教:must 功能,有「依賴上一開關才出現」的誤解點,接著上一步講最順。

3. **【口碑數字一眼看完】** — 特寫元素:`data-tour="review-stats"`
   - 文案:「平均幾分、幾則、各星等多少人都在這。藏起來的也算進去喔。」
   - 為何教:進頁第一眼的價值,順帶澄清「統計含隱藏、不受篩選影響」。

4. **【不想被看到的,藏起來】** — 特寫元素:`data-tour="review-visibility-toggle"`
   - 文案:「遇到垃圾或不實評價,點眼睛讓學員看不到。是隱藏不是刪除,後台還留著。」
   - 為何教:must 功能,「隱藏≠刪除」是最常見誤解,必須當正式步驟。

5. **【有人檢舉?點紅標看原因】** — 特寫元素:`data-tour="review-report-badge"`
   - 文案:「評價被檢舉會冒紅標,點開看原因。真有問題,用旁邊眼睛藏掉就行。」
   - 為何教:must 功能,紅標只有被舉報才出現容易漏看,也要點明「只能看不能清」。

6. **【親自回覆,展現專業】** — 特寫元素:`data-tour="review-reply-box"`
   - 文案:「在這寫回覆,送出後會即時出現在銷售頁,大家都看得到。打錯可再用鉛筆改、垃圾桶刪。」
   - 為何教:這頁最能經營口碑的動作;一句帶過編輯/刪除,並點出「同步到課程頁」。

**可中斷 / 備註:**

- **主中斷點在第 3 步後**:講完「兩個設定 + 看統計」已是完整心智模型,使用者可在此關掉教學自行操作。
- 後 3 步(隱藏、舉報、回覆)是逐則操作技巧,彼此獨立,跳過任一步不影響其他。
- 第 2 步有條件性:若「啟用評價功能」尚未打開,該開關不存在,引擎需偵測元素不存在時自動跳過,並把提示併入第 1 步。
- 「篩選星等」下拉刻意不做步驟(只改列表顯示、不動統計,自助探索即懂);若使用者在列表停留較久,可用一句 hint 提「右上可篩星等」。
- 使用者中途關閉時,標記 tour 為已看過、不再自動彈出;之後可從右上角問號圖示手動重開。
