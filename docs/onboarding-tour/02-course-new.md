# 新手教學設計 — 新增課程

> 路由:`/admin/courses/new` ｜ 對象:第一次建立課程、或要再開一門新課的講師 ｜ 預估教學:約 60 秒(5 步)

## 1. 頁面核心用途
進到這頁,先把一門課最關鍵的資訊(課名、價格、要不要上線)建起來;封面、大綱、促銷這些之後在編輯頁慢慢補。

## 2. 功能梳理(這頁能做什麼)
| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 課程標題 | 輸入課名(必填,2–100 字),建好後會自動帶出下面的網址 | 表單最上方 | ⭐ 必教 |
| 課程網址(Slug) | 自動帶課程網址;純中文課名帶不出來時要自己打英文 | 標題下方 | ⭐ 必教 |
| 課程價格 | 設定原價(必填);填 0 就是免費課,前台會變「免費報名」 | 描述下方 | ⭐ 必教 |
| 課程狀態 | 選草稿/已發佈/隱藏;預設草稿只有自己看得到,要上線得改成已發佈 | 價格下方 | ⭐ 必教 |
| 販售可見性 | 控制誰找得到賣頁:公開、只給連結、私密邀請 | 狀態下方 | ⭐ 必教 |
| 建立課程按鈕 | 填完必填就按,自動跳到編輯頁繼續補封面與大綱 | 表單右下角 | ⭐ 必教 |
| 副標題 | 一句話補充課程賣點(非必填) | Slug 下方 | ◐ 可帶過 |
| 課程描述 | 簡述這門課幫學生解決什麼(非必填) | 副標題下方 | ◐ 可帶過 |
| 返回課程列表 | 左上箭頭回到課程列表(未存內容會不見) | 頁面左上角 | ◐ 可帶過 |

### 容易誤解 / 客戶常漏的點
- 新課預設是「草稿」,只有自己看得到。做完忘了改「已發佈」是最常見的雷,課程會永遠對外不見。
- 「課程狀態」和「販售可見性」是兩回事:狀態還是草稿時,可見性怎麼調都沒用。
- 純中文課名(例如「Python 零基礎入門」)帶不出網址,要自己打英文小寫(如 python-101),只能用小寫字母、數字、連字號。
- 價格填 0 = 免費課,前台會從「購買」變成「免費報名」。
- 選了「私密邀請」的話,建立後還要去編輯頁設邀請碼,不然沒人買得到。
- 副標題、描述、封面、促銷都非必填,可以留到編輯頁再補。

## 3. 新手教學流程
**開場白**(點問號後第一句):
> 「這頁先把一門課最關鍵的資訊建起來,封面、大綱、促銷之後在編輯頁再補。大概一分鐘填完,我帶你走必填欄位跟兩個最容易踩雷的地方。副標題和描述非必填,可以先跳過。」

**逐步引導:**
1. **【先取個課名】** — 特寫元素:`data-tour="course-title"`
   - 文案:「先打課名,例如『Claude AI 工作流實戰班』。必填。」
   - 為何教:唯一要先想清楚的欄位,還會自動帶出下面的網址。

2. **【課程網址】** — 特寫元素:`data-tour="course-slug"`
   - 文案:「網址會自動帶。純中文課名帶不出來,就自己打英文,例如 python-101。」
   - 為何教:新手最常卡在中文帶不出網址,且只能用小寫字母、數字、連字號。

3. **【設定價格】** — 特寫元素:`data-tour="course-price"`
   - 文案:「填原價就好。填 0 就是免費課,前台會變『免費報名』。」
   - 為何教:必填,而且 0 會整個改變賣頁邏輯;促銷價之後在定價頁設。

4. **【記得改成上線】** — 特寫元素:`data-tour="course-status"`
   - 文案:「預設是草稿,只有你看得到。要對外賣,記得改成『已發佈』。」
   - 為何教:最常見的雷——做完忘了發佈,課程永遠對外不見。

5. **【按下建立課程】** — 特寫元素:`data-tour="course-submit"`
   - 文案:「按下去就建好,自動跳到編輯頁補封面跟大綱。建立中別連點。」
   - 為何教:完成動作;順帶提醒下方還有「販售可見性」可控制誰找得到賣頁,跟狀態是兩回事。

**可中斷 / 備註:**
- 每一步之間都是自然中斷點,各欄位獨立。隨時按 Esc 或「跳過」都不影響已填內容。
- 表單是暫存在畫面上的,只要沒重整或按返回就會保留;按左上箭頭返回會清空未存內容。
- 建議從「課程標題」開始,因為它連動網址。中途跳過就停在當下欄位即可,不必回到第一步。
- 想做更短的 3 步精簡版:保留「課程標題 → 課程狀態 → 建立課程」,其餘合併帶過。
- 「販售可見性」與「課程狀態」獨立、最易混淆,若不單獨成步,務必在最後一步用一句話帶到。
