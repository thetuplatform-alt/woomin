# 新手教學設計 — 學員管理

> 路由:`/admin/users` ｜ 對象:管理學員名單、手動授課、批次匯入/匯出、查看學員持有課程的講師與管理員 ｜ 預估教學:約 45 秒(5 步)

## 1. 頁面核心用途

這是你管理所有學員的地方 — 看誰買了哪些課、手動把課送給學員、把舊平台的名單一次搬進來,也能把名單匯出存檔。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 新增用戶 | 手動建一個帳號(學員/講師/管理員),可同時指派課程、寄邀請信 | 右上「新增」按鈕(對話框,僅 ADMIN 顯示) | ⭐ 必教 |
| 角色分頁 | 切換只看 學員 / 講師 / 管理員 / 全部 | 工具列左側分頁(僅 ADMIN 顯示) | ◐ 可帶過 |
| 搜尋 | 用姓名或 Email 找特定學員 | 工具列搜尋框 | ⭐ 必教 |
| 課程篩選 | 只看買了某一門課的學員 | 工具列「全部課程」下拉 | ◐ 可帶過 |
| 購買狀態篩選 | 篩出有買 / 沒買課程的人 | 工具列「購買狀態」下拉 | ✕ 不教 |
| 清除篩選 | 一鍵清掉所有篩選條件 | 篩選右側 X 鈕(有篩選才出現) | ✕ 不教 |
| 匯入學員 | 上傳 CSV 一次匯入多位學員並批次授課,相容 Teachify 格式 | 工具列「匯入學員」按鈕(對話框) | ⭐ 必教 |
| 匯出 CSV | 依當前篩選把學員名單匯出成 CSV | 工具列「匯出 CSV」按鈕 | ◐ 可帶過 |
| 學員列表 | 看每位學員的頭像、Email、角色、電話、已購課程數、註冊日 | 主表格 | ⭐ 必教 |
| 編輯持有課程 | 進單一學員頁,手動加 / 移除他持有的課程 | 每列「編輯持有課程」按鈕 | ◐ 可帶過 |
| 分頁 | 翻頁瀏覽大量學員 | 表格下方分頁列 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點

- 「新增用戶」「角色分頁」只有 **ADMIN** 看得到;講師只能看到自己課程的學員,所以教學步驟若指向這兩個元素,在講師帳號下會自動略過(框架找不到錨點就跳過)。
- 匯入學員時 **一定要先選課程**,沒選課程無法匯入 — 這是最常卡住的地方,匯入步驟文案要點到。
- 匯入相同 Email 不會重複建帳號、已持有的課不會重複授權,可放心重跑。
- 匯出 CSV 是 **跟著當前篩選走** 的,先篩再匯出就只會匯出篩選結果。

## 3. 新手教學流程

**開場白**:
> 「這裡是你的學員名冊 — 誰買了哪門課一目了然。我帶你 45 秒學會找學員、手動送課,還有怎麼把整批名單一次搬進來。」

**逐步引導:**

1. **【手動加一個人】** — 特寫:`users-add-btn` — 文案:「想單獨加一位學員或講師?點這裡,還能順手把課直接送給他。」— 為何教:手動授課是日常最高頻操作,且只有 ADMIN 看得到,放第一步最直覺。
2. **【一次搬一整批】** — 特寫:`users-import-btn` — 文案:「從別的平台搬家?上傳一份 CSV,整批學員連同課程一次匯入。記得先選課程。」— 為何教:批次匯入是新站搬家的關鍵,且容易漏選課程,需提醒。
3. **【匯出存檔】** — 特寫:`users-export-btn` — 文案:「想備份名單?照你現在的篩選,一鍵匯出成 CSV。」— 為何教:讓使用者知道資料可帶走,順帶點出「跟著篩選走」。
4. **【找特定學員】** — 特寫:`users-filters` — 文案:「人多了就用這裡:打姓名或 Email 搜尋,也能只看買了某門課的人。」— 為何教:搜尋與篩選是名單變大後的核心工具。
5. **【名單都在這】** — 特寫:`users-table` — 文案:「所有學員列在這:買了幾門課、何時註冊都看得到。點右側可調整他持有的課程。」— 為何教:表格是頁面主體,收尾帶到「編輯持有課程」入口。

**可中斷 / 備註:**

- 任何一步都可關閉,框架支援隨時中斷。
- 步驟 1(新增)指向的 `users-add-btn` 在 **講師帳號** 下不存在,框架會自動略過該步,教學仍可順暢進行。
- 步驟 2、3 指向的是開啟對話框的常駐觸發按鈕(匯入 / 匯出),文案對齊那顆按鈕的動作,對話框內部流程不另做特寫(對話框開啟前不在 DOM)。
