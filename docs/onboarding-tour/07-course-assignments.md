# 新手教學設計 — 作業 / 測驗

> 路由:`/admin/courses/[id]/assignments` ｜ 對象:要出作業/測驗、批改、看學員成績的講師或助教 ｜ 預估教學:約 55 秒(5 步)

## 1. 頁面核心用途

這頁是你批改作業、看測驗成績的地方。這門課所有作業和測驗都集中在這,哪份還沒改、哪場測驗考得怎樣,一眼就看到。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 統計摘要卡 | 一眼看這課有幾份作業、幾場測驗、收到幾份提交 | 頁面最上方三張卡片 | ⭐ 必教 |
| 單元列表 | 看每個單元有沒有作業/測驗、多少人交,點進去批改或查看 | 下方大表格 | ⭐ 必教 |
| 批改作業(入口) | 點按鈕進入批改視窗,逐份改學員作業 | 表格右側「批改作業」(有人交才出現) | ⭐ 必教 |
| 查看作答結果(入口) | 點按鈕進入測驗成績,看全班與逐題對照 | 表格右側「查看作答結果」(有人答才出現) | ⭐ 必教 |

### 容易誤解 / 客戶常漏的點

- **「0 份提交」不一定是沒人寫** — 學員只存草稿、還沒按送出的,這裡不會算進去。看到 0 別急著以為沒人交。
- **評語會直接 Email 寄給學員** — 評語不是寫給自己看的,一送出就立刻寄出。寫之前確認語氣 OK。
- **結果一定要三選一** — 評語可以不寫,但「通過 / 退回修改 / 不通過」一定要選一個,不然送不出去。
- **退回後重交,版本會跳號** — 學員被退回重新上傳,會顯示 v2、v3,幫你認出這是改過的版本。
- **分數方式是建作業時就定好的** — 通過制/百分制/等第制不能批改時臨時改;批改欄位會自動跟著切換。
- **同一份可以改很多次,後面蓋前面** — 但每次紀錄都留在「歷史批改」裡可查。
- **測驗可重考時會有多列同一個人** — 系統不會自動合併,要自己判斷算哪一次;匯出的 CSV 也是一列一次。

## 3. 新手教學流程

**開場白**(點問號後第一句):

> 「這頁是你改作業、看測驗成績的地方。哪份還沒改、哪場考得怎樣,一眼就懂。我帶你走一遍批改流程。」

**逐步引導:**

1. **【先看整課規模】** — 特寫元素:`data-tour="assignments-summary"`(最上方三張統計卡外層 grid)
   - 文案:「這課有幾份作業、幾場測驗、收到幾份提交,這裡看完。下面那條是附件空間,快滿會變黃。」
   - 為何教:落地第一秒建立全貌,順手把儲存監控帶過,不另開步驟。

2. **【在這找要改的對象】** — 特寫元素:`data-tour="lessons-table"`(下方單元列表 Card)
   - 文案:「有作業或測驗的單元都列在這。看『提交/作答』就知道有沒有人交。0 份有時是學員還在打草稿,不是沒人寫。」
   - 為何教:這是全頁導航核心;同時點破「草稿不計數」這個最常誤判的點。

3. **【點這顆開始批改】** — 特寫元素:`data-tour="grade-assignment-btn"`(表格右側「批改作業」按鈕)
   - 文案:「有人交才會出現這顆。點進去就能一份份改。測驗則是點旁邊『查看作答結果』。」
   - 為何教:進入批改流程的入口;順帶一句帶出測驗那條主線,避免另開步驟。

4. **【先挑待批改的下手】** — 特寫元素:`data-tour="submission-stats"`(批改視窗上方五格統計卡)
   - 文案:「黃色那格『待批改』就是你還沒處理的,先從這幾份開始最快。上面也能只篩待批改來看。」
   - 為何教:建立「先處理待批改」的節奏,避免漫無目的;順手帶過狀態篩選。

5. **【看內容、寫評語、選結果】** — 特寫元素:`data-tour="review-form"`(批改面板的提交內容 + 評語/分數 + 三顆結果按鈕)
   - 文案:「上面是學員交的文字圖片附件,圖片可放大。下面寫評語、給結果。⚠️ 結果一定要選一個,評語會直接 Email 給學員。」
   - 為何教:整個批改的成交動作,最關鍵;務必講清「結果必選」和「評語會寄出去」兩個一送出就無法挽回的點。

**可中斷 / 備註:**

- **最舒服的離開點是第 1~3 步**(都在主頁面)。看完第 3 步「點這顆開始批改」前隨時可走。
- **第 4、5 步要批改視窗裡真的有提交才看得到**。若這課所有作業提交數都是 0(批改按鈕不存在),自動跳過第 4、5 步,只跑 1、2、3。
- **第 5 步錨定在彈出視窗內**:若使用者自己關掉視窗,教學偵測到目標消失就優雅結束,不要卡住。
- 任何一步都能按 Esc 或「略過導覽」離開。中途離開會記住看到第幾步,下次點問號可選「從頭」或「接續」,不強制看完。
- 測驗那條(查看作答結果、逐題檢視、匯出 CSV)在第 3 步用一句話帶過即可,不另開步驟,以維持「快速帶過」。
