# 新手教學設計 — 定價與促銷

> 路由:`/admin/courses/[id]/pricing` ｜ 對象:要設定課程售價、打折、免費課程,以及學員能看多久的講師 ｜ 預估教學:約 70 秒(4 步)

## 1. 頁面核心用途

這頁是課程「賺錢的開關」:設定要賣多少錢、要不要打折、學員買了能看多久,還能發專屬折扣碼。把幾個關鍵欄位填好,課程就能上架收錢。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 設定原價 | 打入課程定價(台幣);想做免費課就填 0 | 定價設定卡片，左上輸入框 | ⭐ 必教 |
| 設定促銷價 | 打入打折後的價格,留空就是不打折 | 定價設定卡片，右上輸入框 | ◐ 可帶過 |
| 促銷說明文字 | 自訂折扣理由(如「開工優惠」),最多 20 字,空白顯示「限時優惠」 | 定價設定卡片，說明文字欄 | ◐ 可帶過 |
| 設定促銷截止日期 | 選打折活動何時結束(要晚於現在) | 未開永久優惠時的日期欄 | ⭐ 必教(有打折時) |
| 永久優惠開關 | 讓折扣永遠有效,不設截止日 | 定價設定卡片，循環箭頭開關 | ◐ 可帶過 |

### 容易誤解 / 客戶常漏的點

- **改「能看多久」只影響之後買的人**,已經買過的學員權限不會變動。要改舊學員得去他的購買紀錄個別調整,這頁改不到。
- **想做免費課,原價直接填 0** 就好,不用其他設定。
- **有打折卻沒設截止日,系統會提醒你補一個**;想長期降價就改開「永久優惠」(開了就不用設日期)。
- **截止日期必須晚於現在**,設到過去的時間會存不了。
- **「固定到期日」是所有學員同一天一起斷**,沒有例外,設之前要想清楚。
- **永久授權不會寄到期提醒**(因為永遠不過期),選永久授權時提醒選項會自動關。
- **促銷價和優惠券是兩套折扣,可以同時用**,買家兩個都享受到;優惠券要去它自己的編輯頁改,這頁只能看跟開關。
- **有改動,底部黃色「儲存變更」列才會冒出來**;沒看到那條,代表目前沒有要存的東西。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這頁決定課程賣多少錢、學員能看多久。我帶你把最關鍵的幾格設好就能上架,大概一分鐘。」

**逐步引導:**

1. **【先填原價】** — 特寫元素:`data-tour="pricing-original-price"`(定價卡片左上「原價 (NT$)」輸入框)
   - 文案:「先打入課程價格。想做免費課就填 0。」
   - 為何教:這格不填存不了,後面打折也是拿它當基準。

2. **【要打折再設促銷】** — 特寫元素:`data-tour="pricing-sale-block"`(原價右邊「促銷價」欄與下方開關區)
   - 文案:「想打折就填促銷價,記得設『截止日期』。長期降價就開『永久優惠』。」
   - 為何教:不打折這步可整段跳過;有促銷沒截止日系統會提醒你補。

3. **【決定能看多久】** — 特寫元素:`data-tour="access-type-select"`(授權期限卡片的「授權類型」下拉選單)
   - 文案:「選永久、期限或固定到期日。注意:改了只影響之後買的人。」
   - 為何教:這是你給學員的承諾,選「期限」會多跳出填天數的欄位。

4. **【按下儲存才算數】** — 特寫元素:`data-tour="sticky-save-bar"`(頁面底部浮動「儲存變更」按鈕)
   - 文案:「有改動底部就會冒出這條,按它才會存。沒按就離開會被攔下。」
   - 為何教:這頁所有設定都靠這顆一次送出,看到綠色成功提示才完成。

**可中斷 / 備註:**

- 每一步對應一個獨立區塊(定價 → 授權 → 儲存),講師可在任何一步關掉導覽,已填的欄位都會留著。
- 硬骨幹是第 1、3、4 步(原價必填、決定能看多久、存檔才生效);**跳過第 2 步(打折)課程照樣能上架**。
- 跳過整個導覽也沒關係:左側四個分類(定價設定 / 授權期限 / 到期提醒 / 課程優惠券)隨時可點回看,右上問號可重新打開導覽。
- 手機上左側導航會收起來,導覽偵測到窄螢幕時,第 3 步會改提示「先展開選單,找到『授權期限』」。
- 到期提醒、循環天數、優惠券管理都是進階選項,刻意不放進正式步驟,免得第一次設定的人卡住。
