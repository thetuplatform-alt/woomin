# 新手教學設計 — 課程留言（全課程總表）

> 路由:`/admin/comments` ｜ 對象:想跨所有課程一次掃完、回覆、清理單元留言的講師／管理員 ｜ 預估教學:約 25 秒(4 步)

## 1. 頁面核心用途
這頁把你「所有課程」的學員留言攤在一張表上,不用一門一門點進去。你可以用上方下拉只看某一門課,直接在這裡回覆或刪除留言。

> 注意:這頁是**跨課程總表**(`AllCommentsTable`)。單一課程的留言對話台在 `/admin/courses/[id]/comments`,那頁有自己的教學(見 `08-course-comments.md`),別跟這頁混淆。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 全課程留言表格 | 一張表看所有課程的每則留言:課程、章節、單元、留言者、時間、內容 | 頁面中央表格 | ⭐ 必教 |
| 課程篩選下拉 | 從「全部可管理課程」切成只看某一門課的留言 | 表頭右側下拉選單 | ⭐ 必教 |
| 回覆留言 | 按「回覆」開彈窗,公開回大家看或私下寄 email 給本人 | 每列右側「回覆」鈕 → 彈窗 | ⭐ 必教 |
| 軟刪除留言 | 刪掉後前台不顯示,但後台留紀錄;沒有還原鍵,刪了救不回 | 每列右側紅色「刪除」鈕 + 確認彈窗 | ⭐ 必教 |
| 匿名留言看得到本名 | 學員勾匿名,前台只寫「學員(匿名)」,但這裡會給你他的真名+信箱 | 留言者欄的「匿名」標籤與下方「真實身份」那行 | ◐ 可帶過 |
| 未刪留言總數 | 看你所有(或篩選後)課程目前有幾則留言 | 標題下方「共 X 則未刪除留言」 | ◐ 可帶過 |
| 快速跳到課程內容 | 點表格內課程／章節／單元的文字直接跳到該課編輯頁 | 表格各欄的連結文字 | ◐ 可帶過 |
| 載入更多(無限分頁) | 按「載入更多」往下接續顯示更多留言 | 表格下方「載入更多」鈕 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點
- **這頁沒有未讀紅點機制。** 想看「哪則還沒回」、按單元分組管理,請進單一課程的留言頁,那頁才有未讀標記。
- **回覆彈窗預設是「只寄 email」,不是公開回。** 想讓全班看到,要在彈窗內自己補勾「發送留言」。
- **刪除救不回來。** 只是前台隱藏,沒有「還原」鍵,誤刪要找工程師。
- **匿名留言你看得到本名。** 公開回覆時別直接打學員名字,以免洩漏身份。
- **下拉只列「你可管理」的課程。** 不是你帶的課不會出現在這裡。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這頁把你所有課程的學員留言攤成一張表,不用一門一門點。25 秒帶你學會篩選、回覆、刪除。」

**逐步引導:**

1. **【所有留言都在這張表】** — 特寫:`data-tour="comments-table"`
   - 文案:「你各課的留言全列在這。課程、單元、誰留的、內容,一眼掃完。」
   - 為何教:這是整頁主體,先讓使用者知道不用逐課點開,所有留言集中在這。

2. **【只想看某一門課?用這個篩選】** — 特寫:`data-tour="comments-course-filter"`
   - 文案:「課太多看不完?從這裡挑一門課,表格就只留那門的留言。」
   - 為何教:跨課表格量大,篩選是降噪的關鍵入口,放第二步銜接最自然。

3. **【按回覆:公開回或私下寄信】** — 特寫:`data-tour="comments-table"`(回覆鈕在每列右側,隨表格出現)
   - 文案:「每列右邊有「回覆」。寫好內容,預設只寄 email 給他;想全班看到要自己勾「發送留言」。」
   - 為何教:回覆是核心動作,且「預設只寄 email」是最大誤區。回覆鈕只在有留言的列才出現,故錨定常駐的表格、文案指向列內按鈕。

4. **【刪除是軟刪除,救不回來】** — 特寫:`data-tour="comments-table"`(刪除鈕在每列右側)
   - 文案:「紅色「刪除」會把留言下架,前台看不到。但沒有還原鍵,誤刪要找工程師。」
   - 為何教:不可逆高風險,務必先警告。刪除鈕同樣只在留言列出現,故沿用表格錨點。

**可中斷 / 備註:**
- **最小必走路徑 = 第 1 步 + 第 2 步**(看懂表格 + 學會篩選)。趕時間者保留這兩步即可。
- **回覆鈕、刪除鈕只在「有留言的列」才在 DOM**,因此不單獨加錨點,改錨定常駐的 `comments-table`,文案明確指向列內那兩顆按鈕;空表格時框架仍能正常停在表格上。
- **第 4 步(軟刪除不可逆)即使被跳過,也建議至少曝光一次警告**,避免誤刪救不回。
- 標題的「共 X 則未刪除留言」、匿名身份揭示、表內跳轉連結、載入更多皆為可帶過/不教項,不單列步驟。
