# 新手教學設計 — 儀表板

> 路由:`/admin` ｜ 對象:講師 / 管理員登入後第一個看到的總覽頁 ｜ 預估教學:約 40 秒(4 步)

## 1. 頁面核心用途

這是後台首頁,讓你登入後一眼掌握平台現況 — 賺多少、賣幾單、學員多少、課賣得好不好,並提供常用操作的快捷入口。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 統計卡片 | 看本月營收、本月訂單、總營收、總學員數、平均完課率、課程數量(含與上月增減) | 頂部六張卡片 | ⭐ 必教 |
| 銷售趨勢圖 | 看一段時間內的銷售走勢,右上角可切換時間範圍 | 第一排圖表左側(佔 2/3) | ⭐ 必教(以整排圖表帶過) |
| 付款方式分布 | 看各付款方式占比 | 第一排圖表右側 | ◐ 可帶過 |
| 用戶成長趨勢 | 看註冊用戶累積成長 | 第二排圖表左側 | ◐ 可帶過 |
| 每日學習人數 | 看每天有多少學員在學習 | 第二排圖表右側 | ◐ 可帶過 |
| 轉換漏斗 | 看從瀏覽到購買的逐步轉換率(需 PostHog) | 第三排圖表左側 | ✕ 不教 |
| 熱門課程排行 | 看銷量前幾名的課程 / 組合包,可點進該課 | 第三排圖表右側 | ◐ 可帶過 |
| 快速操作 | 一鍵前往新增課程、查看訂單、管理學員 | 底部左側卡片 | ⭐ 必教 |
| 最近訂單 | 看最新成交紀錄,可跳到完整訂單列表 | 底部右側卡片 | ⭐ 必教 |
| 平台更新通知 | 有新版時提示升級指令 | 頁面最上方(無更新時不顯示) | ✕ 不教(非常駐) |

> 註:講師(非 ADMIN)看到的是精簡版 `InstructorDashboard`,只有「我的課程 / 學員 / 營收」三張卡與課程清單,不含全站趨勢圖。本教學以管理員完整版為主,文案對講師也成立。

### 容易誤解 / 客戶常漏的點

- 每張趨勢圖**右上角各自有時間範圍切換**,不是全頁共用一個;客戶常以為改不了時間。
- 圖表資料是**載入後才填入**的,剛進頁面可能短暫顯示「載入中」或「暫無數據」,不是壞掉。
- 新站初期所有數字都是 0 / 暫無數據是正常的,開始賣課後才會有內容。
- 轉換漏斗依賴 PostHog 設定,未設定時顯示暫無數據,屬正常。

## 3. 新手教學流程

**開場白:**
> 「這是你的營運總覽 — 登入後第一眼就看到平台現在的狀況。我帶你 40 秒看懂這頁怎麼讀、要從哪裡開始做事。」

**逐步引導:**

1. **【六個關鍵數字一眼看完】** — 特寫:`dashboard-stats` — 文案:「營收、訂單、學員、完課率全在這。每天進來先掃一眼這排卡片就對了。」— 為何教:這是客戶每天最常看的數字,先建立「先看這排」的習慣。
2. **【趨勢圖看生意走向】** — 特寫:`dashboard-charts`(整排圖表) — 文案:「銷售、付款方式、用戶成長都畫成圖。每張右上角可換時間範圍。」— 為何教:用一步帶過所有趨勢圖,並點破「各圖各自切時間」這個常見誤解。
3. **【常用功能的捷徑】** — 特寫:`dashboard-quick-actions` — 文案:「想開新課、看訂單、管學員?從這三顆按鈕直接過去,不用繞選單。」— 為何教:把客戶從「看數據」導向「開始做事」,降低新手不知從何下手的卡點。
4. **【最新成交都在這】** — 特寫:`dashboard-recent-orders` — 文案:「誰剛買了什麼、付了沒,這裡即時顯示。點『查看全部』看完整訂單。」— 為何教:成交是平台主目的,讓客戶知道哪裡能即時看到金流動態與入口。

**可中斷 / 備註:**

- 全部錨點都是頁面初次載入即在 DOM 的常駐容器(歡迎區、統計卡片區、第一排圖表區、快速操作卡、最近訂單卡),不依賴對話框或 hover。
- 趨勢圖採延後載入,聚光燈打在外層容器(`dashboard-charts`)而非圖表本身,即使圖仍在載入中錨點依然存在、不會落空。
- 平台更新橫幅(`UpdateBanner`)多數情況不顯示,刻意不做錨點。
- 轉換漏斗、付款方式、每日學習人數等次要圖表併入「趨勢圖」一步帶過,維持 4 步精簡。
- 講師版儀表板版面不同(無趨勢圖),框架找不到的錨點會自動略過,文案語氣對講師仍適用。
