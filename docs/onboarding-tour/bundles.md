# 新手教學設計 — 課程組合包

> 路由:`/admin/bundles` ｜ 對象:想把多門課綁成一個組合商品販售的講師 ｜ 預估教學:約 35 秒(4 步)

## 1. 頁面核心用途

把現有的好幾門課打包成「一個」可購買的組合商品,給它專屬銷售頁、自訂價格,讓學生一次買齊、你一次成交。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 建立新組合包 | 點「新增組合包」開一個全新組合,把多門課綁成一個商品 | 右上角按鈕(加號) | ⭐ 必教 |
| 查看組合包列表 | 一張表看完所有組合:名稱、狀態、課程數、價格、更新時間 | 頁面中央表格 | ⭐ 必教 |
| 看「狀態」標籤 | 一眼分辨草稿(灰)、已發佈(綠)、已停用(黃) | 表格「狀態」欄 | ⭐ 必教 |
| 看課程數 | 看到這個組合內含幾門課 | 表格「課程數」欄 | ◐ 可帶過 |
| 看組合價格 | 看到原價,以及促銷價(原價會帶刪除線) | 表格「價格」欄 | ◐ 可帶過 |
| 編輯組合包 | 點鉛筆圖示進編輯頁,改名稱、價格、內含課程 | 表格最右欄 | ⭐ 必教 |
| 預覽銷售頁 | 點外開圖示,新分頁打開前台 `/bundles/{slug}` 銷售頁 | 表格最右欄 | ◐ 可帶過 |
| 複製銷售頁連結 | 點複製圖示,把組合銷售頁網址複製到剪貼簿 | 表格最右欄 | ◐ 可帶過 |
| 停用組合包 | 點封存圖示,把上架中的組合下架(不販售但保留資料) | 表格最右欄 | ◐ 可帶過 |
| 空狀態提示 | 還沒有組合時,提示去建立第一個組合包 | 表格區域 | ⭐ 必教 |
| 看更新時間 | 看到每個組合最後更新的日期 | 表格「更新時間」欄 | ✕ 不教 |

### 編輯頁(進入後)能做什麼 — 本頁帶過、不單獨教

- 填名稱 / Slug / 描述 / 上傳封面
- 設原價與促銷價、設狀態(草稿 / 發佈 / 停用)、設可見性(公開 / 不公開)
- 勾選內含課程,並用「上移 / 下移」排課程顯示順序

### 容易誤解 / 客戶常漏的點

- **「狀態」決定學生買不買得到。** 停在「草稿」時前台銷售頁不會公開,要改成「已發佈」才賣得出去。
- **組合包是獨立商品,不是折扣券。** 它有自己的銷售頁和價格;買組合=一次解鎖裡面所有課,跟單買那些課是兩條路。
- **記得設「內含課程」。** 在編輯頁勾選課程才算數;沒勾課的組合等於空殼,學生買了也拿不到東西。
- **「已停用」≠ 刪除。** 停用只是下架不再販售,資料還在、之後可再編輯;這頁沒有永久刪除。
- **促銷價要低於原價才有意義。** 列表會把原價畫刪除線、顯示促銷價,沒填促銷價就只顯示原價。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「想把好幾門課打包成一個商品一次賣?這頁就是。我帶你 35 秒學會建組合、看懂狀態、進去改。」

**逐步引導:**

1. **【從這裡打包一個新組合】** — 特寫:`data-tour="bundles-new-btn"`
   - 文案:「想把多門課綁成一個商品賣?點這裡。先存成草稿,慢慢挑課、定價。」
   - 為何教:這是建立組合的唯一入口,新手第一件事就是開第一個組合;順手帶出「草稿」概念。

2. **【你的組合都在這張表】** — 特寫:`data-tour="bundles-table"`
   - 文案:「所有組合列在這。內含幾門課、賣多少、什麼狀態,一眼掃過去。」
   - 為何教:建立整頁心智地圖,知道每一欄在看什麼,為後面的狀態與操作鋪路。

3. **【「狀態」決定學生買不買得到】** — 特寫:`data-tour="bundles-status-column"`
   - 文案:「草稿=只有你看得到,已發佈=學生才買得到,已停用=下架但資料還在。」
   - 為何教:最高頻踩雷點 — 組合做好了卻沒人買到,通常就是還停在草稿,必須講清楚。

4. **【改內容、預覽、複製連結都在這】** — 特寫:`data-tour="bundles-actions-column"`
   - 文案:「鉛筆進去改名稱、價格跟內含課程;另外可預覽銷售頁、複製連結拿去推。」
   - 為何教:進編輯頁挑課定價是組合的核心動作,順手把預覽 / 複製連結一次帶完,收尾完整。

**可中斷 / 備註:**

- 全程唯讀,不會替使用者建組合、改內容或停用;任何一步結束都可隨時關閉,不影響頁面。
- 自然中斷點:**第 1 步後**(已學會建組合)、**第 3 步後**(已搞懂狀態)— 各自是完整小目標,提前離開也拿到關鍵知識。
- 中途跳過直接關閉即可,毋需復原任何 UI;再次點問號從第 1 步重新開始,不保留進度。
- **空狀態(還沒有任何組合)時**,第 2~4 步的表格錨點不存在,框架自動跳過,只留第 1 步建組合引導,呼應頁面本身的空狀態提示。
- 第 2~4 步的錨點(`bundles-table`、`bundles-status-column`、`bundles-actions-column`)都在列表表格上;編輯頁(`/admin/bundles/new`、`/admin/bundles/[id]`)為另一路由,不在本頁教學範圍。
