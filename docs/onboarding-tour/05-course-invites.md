# 新手教學設計 — 邀請連結

> 路由:`/admin/courses/[id]/invites` ｜ 對象:想免費把課程送給特定對象(合作夥伴、特定學生、推廣名單)的講師 ｜ 預估教學:約 40 秒(3 步)

## 1. 頁面核心用途

這頁是「發免費入場券」的地方:產一條邀請連結、複製貼給對方,對方點開就能直接拿到課程,不用付錢。可以全部人通用,也可以限定某個人、限次數、設到期時間。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 建立邀請連結 | 按「建立」就產一條免費入場連結,3 格全留空 = 誰都能用 | 上半部「建立邀請」卡片,右側「建立」按鈕 | ⭐ 必教 |
| 複製邀請網址 | 連結建好後一鍵複製完整網址,直接貼給對方 | 「新邀請已建立」卡片的「複製邀請網址」按鈕 | ⭐ 必教 |
| 查看所有發過的邀請 | 下方表格列出每一條邀請的狀態、用了幾次、到期時間 | 下半部「邀請紀錄」卡片表格 | ⭐ 必教 |
| 停用某條邀請 | 按該列「停用」,新人就不能再用這條(已拿到的人不受影響) | 紀錄表格右側「操作」欄 | ◐ 可帶過 |
| 限定 Email 給特定人用 | 填一個 Email,只有用那個帳號登入的人能用這條 | 「限制 Email」欄位(可留空) | ◐ 可帶過 |
| 限制使用次數 | 填數字,例如填 5 代表這條最多被用 5 次 | 「使用上限」欄位(可留空) | ◐ 可帶過 |
| 設定到期時間 | 選日期時間,過了就自動失效 | 「到期時間」欄位(可留空) | ◐ 可帶過 |
| 看狀態標籤 / 使用次數 | 綠色「可使用」代表還能用;「3 / 5」代表已用 3 次 | 表格「狀態」欄、「使用次數」欄 | ◐ 可帶過 |
| 複製 token | 複製一串純代碼(進階用途,一般講師用不到) | 「複製 token」按鈕 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點

- **建好後一定要馬上複製。** 那條網址離開這頁就再也看不到了,系統不會幫你留底,沒複製到就只能重發一條。
- **「複製 token」按鈕不用理它。** 一般發課只要按「複製邀請網址」就好;token 是給進階串接用的,複製出來貼給學生反而看不懂。
- **「限制 Email」留空 ≠ 完全公開。** 對方還是要先登入(註冊)才能用,只是不限定是誰。
- **「停用」收不回已經發出去的權限。** 已經用這條連結拿到課的學生照樣能看,停用只是擋住「之後的新人」。
- **到期 / 用完不能「續期」。** 過期或用完就失效,沒辦法延長,要再發只能建一條新的。
- **這條連結只對「這門課」有效。** 不能拿去別門課用。

## 3. 新手教學流程

**開場白**(點問號後第一句):
> 「這頁是你發免費課程入場券的地方:產一條連結,複製貼給對方,他點了就直接有課,免付錢。30 秒帶你走一遍。」

**逐步引導:**

1. **【先按「建立」產一條】** — 特寫元素:`data-tour="invite-create-button"`(「建立邀請」卡片右側的建立按鈕)
   - 文案:「上面三格全留空,直接按『建立』,就有一條誰都能用的連結。」
   - 為何教:這是全頁最核心、客戶最常做的動作。先給最快路徑,限制選項之後再說。

2. **【建好馬上複製,只給看一次】** — 特寫元素:`data-tour="invite-copy-buttons"`(「新邀請已建立」卡片的「複製邀請網址」按鈕)
   - 文案:「按『複製邀請網址』貼給對方就行。離開這頁就看不到了,現在一定要複製!」
   - 為何教:全頁最大地雷。網址只顯示一次,錯過要重發。(旁邊的「複製 token」按鈕不用管。)

3. **【發過的全在這查、想停在這停】** — 特寫元素:`data-tour="invite-records-table"`(下半部「邀請紀錄」卡片表格)
   - 文案:「發過的連結都在這。綠色『可使用』就是還有效,要停掉哪條按右邊『停用』。」
   - 為何教:檢視紀錄是必教功能;順帶把狀態標籤、使用次數、停用按鈕一次講完。

**(以下為可選補充,預設不主動教,客戶問再帶):想加門檻,建立時填那三格 —— 填 Email 只給那人用、填數字限次數、選日期到期失效,都可留空。** 對應 `data-tour="invite-options"`。

**可中斷 / 備註:**
- **安全中斷點:第 1 步後**(客戶已會產連結)、**第 3 步後**(已掌握查詢與停用)。主流程到第 3 步即完整。
- **第 2 步不可被悄悄跳過:** 「網址只看一次」這個地雷錯過代價高。若客戶在進到第 2 步前就關掉導覽,UI 應在「複製邀請網址」按鈕區保留一個常駐小提示(如卡片標題旁的驚嘆號圖示),避免他忘記複製。
- **第 2 步是條件出現的卡片**(只有剛建立完邀請才會冒出來)。若導覽啟動時還沒有任何新邀請,這步應自動跳過,或改指向「建立」按鈕並預告一句「建好後記得馬上複製」。
- 三個門檻欄位屬補充,跳過不影響完成基本任務。
