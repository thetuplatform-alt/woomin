# 新手教學設計 — 講師管理

> 路由:`/admin/instructors` ｜ 對象:站長 / 主管理員(只有 ADMIN 進得來) ｜ 預估教學:約 35 秒(4 步)

## 1. 頁面核心用途

這頁讓你把團隊成員拉進來一起經營:指定誰是「講師」、誰是「管理員」,並隨時調整每個人的權限。沒有設好權限,別人就動不了後台。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 新增講師 / 管理員 | 點右上「新增」→ 用 email 搜尋既有用戶設為講師/管理員,查無此人可直接新建並寄邀請信 | 右上「新增」下拉按鈕 → 對話框 | ⭐ 必教 |
| 團隊概況統計 | 一眼看到目前有幾位管理員、幾位講師 | 上方兩張統計卡 | ◐ 可帶過 |
| 注意事項提醒 | 提醒「至少留一位管理員、不能改自己、降級會移除權限、即時生效」 | 黃色警告卡 | ⭐ 必教(避免誤操作) |
| 權限管理表 | 看到所有具權限的成員:頭像、姓名、Email、角色、建立日期、操作筆數 | 「權限管理」卡內表格 | ⭐ 必教 |
| 切換成員角色 | 每列用下拉直接改成 管理員 / 講師 / 學員,會跳確認框 | 表格「角色」欄的下拉 | ⭐ 必教(錨在表格) |
| 操作記錄筆數 | 看每位成員在後台做過幾筆操作 | 表格「操作記錄」欄 | ✕ 不教 |

### 容易誤解 / 客戶常漏的點

- 「新增」不是直接建新帳號,而是先搜尋既有用戶;對方已經是註冊學員時,設為講師就好,不必重建。
- 改角色的下拉**就在表格列裡**,很多人找不到怎麼升降權限。
- 把人降成「學員」會直接拔掉他的後台權限,不是只換個標籤。
- 你**改不了自己的角色**,也不能把最後一位管理員拿掉,系統會擋。
- 角色一改**立刻生效**,不用重新登入。

## 3. 新手教學流程

**開場白:**
> 「這裡是你的團隊管理室 — 誰能教課、誰能管後台,你說了算。我帶你 35 秒學會找人、給權限、改角色。」

**逐步引導:**

1. **【先把人拉進來】** — 特寫:`instructors-add-btn` — 文案:「想找人一起經營?點這裡。用 email 搜既有用戶,設成講師或管理員;查無此人也能直接新建。」— 為何教:這是這頁最主要的入口,沒它就沒有團隊。
2. **【團隊有幾個人一眼看】** — 特寫:`instructors-stats` — 文案:「目前幾位管理員、幾位講師,這兩張卡直接告訴你。」— 為何教:快速建立全局感,可帶過。
3. **【動手前先看這幾條】** — 特寫:`instructors-warnings` — 文案:「改權限前掃一眼:至少留一位管理員、改不了自己、降成學員會拔掉權限,而且一改就生效。」— 為何教:這頁最容易誤操作,先打預防針。
4. **【在這張表升降權限】** — 特寫:`instructors-table` — 文案:「所有有權限的人都在這。要升降誰,點他那列「角色」欄的下拉換一下,會跳確認再生效。」— 為何教:核心操作就藏在表格列的下拉,務必指出來。

**可中斷 / 備註:**

- 新增對話框、角色確認框都是點擊後才出現,不錨定;改錨到常駐的「新增」按鈕與表格,文案對齊那兩個觸發點。
- 角色切換下拉是每列才有、且空表時不存在,因此錨在整張「權限管理」表格(`instructors-table`),而非單一下拉。
- 全程隨時可關閉,不阻擋實際操作。
