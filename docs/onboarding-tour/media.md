# 新手教學設計 — 媒體中心

> 路由:`/admin/media` ｜ 對象:要上傳/管理圖片、影片、附件的講師與內容管理者 ｜ 預估教學:約 40 秒(5 步)

## 1. 頁面核心用途

這是平台所有「上傳到伺服器的檔案」的總覽中心 — 一眼看出影片、圖片、附件各有多少、佔多少空間,並從這裡進到各自的檔案庫上傳與管理。

## 2. 功能梳理(這頁能做什麼)

| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| YouTube 提醒 | 理解影片庫只收 Cloudflare 影片,YouTube 課程不會出現在這 | 頂部灰色提示卡 | ⭐ 必教(最常被誤解) |
| 統計概覽 | 看影片/圖片/附件數量與總儲存空間 | 四張統計卡 | ⭐ 必教 |
| 進影片庫 | 查看/上傳 Cloudflare Stream 影片 | 「最近影片」卡 + 查看全部 | ⭐ 必教 |
| 進圖片庫 | 查看/上傳圖片(課程封面、素材) | 「最近圖片」卡 + 查看全部 | ⭐ 必教 |
| 進文件庫 | 查看/上傳 PDF、作業附件等可下載文件 | 「最近文件」卡 + 查看全部 | ⭐ 必教 |
| 圖片上傳 | 拖放/選檔上傳圖片,可多檔並行 | 子頁 `/admin/media/images` | ◐ 可帶過(進子頁才有) |
| 影片上傳 | 拖放/選檔上傳,大檔自動分塊,可查狀態 | 子頁 `/admin/media/videos` | ◐ 可帶過(進子頁才有) |
| 附件上傳 | 上傳檔案、設「允許下載」、PDF 動態浮水印 | 子頁 `/admin/media/attachments` | ◐ 可帶過(進子頁才有) |
| 總儲存空間 | 監控用量(掛永久硬碟時尤其重要) | 第四張統計卡 | ✕ 不單獨教(併入統計) |

### 容易誤解 / 客戶常漏的點

- **YouTube 影片不會出現在這裡**:多數客戶用 YouTube 貼網址,會疑惑「為什麼媒體中心是空的」。這要第一個講清楚。
- **上傳動作在子頁,不在這頁**:這頁是總覽,真正拖放上傳的拖放區在點進影片庫/圖片庫/文件庫之後。教學文案要對齊「點進去才能上傳」。
- **附件的「允許下載」與「PDF 浮水印」**在文件庫上傳時才設定,是防盜課的關鍵,但屬子頁細節,總覽教學只帶到入口。

## 3. 新手教學流程

**開場白**:
> 「這裡是你所有上傳檔案的家 — 影片、圖片、附件全在這。我帶你 40 秒看懂怎麼分類、怎麼進去上傳。」

**逐步引導:**

1. **【先搞懂影片怎麼算】** — 特寫:`media-youtube-notice` — 文案:「重點先講:這裡只收上傳到平台的影片。用 YouTube 的課,貼網址就好,不會出現在這。」— 為何教:這是最高頻誤解,先講省掉大量困惑。
2. **【一眼看用了多少】** — 特寫:`media-stats` — 文案:「影片、圖片、附件各有幾個、佔多少空間,這排卡片一次看完。」— 為何教:建立全局概念,也提醒儲存用量。
3. **【影片進這裡上傳】** — 特寫:`media-videos-card` — 文案:「平台託管的影片放這。點「查看全部」進影片庫,就能拖檔上傳,大檔會自動分塊。」— 為何教:指出影片上傳入口。
4. **【圖片進這裡上傳】** — 特寫:`media-images-card` — 文案:「課程封面、素材圖放這。進圖片庫可一次拖很多張,平行上傳。」— 為何教:指出圖片上傳入口。
5. **【文件附件進這裡】** — 特寫:`media-attachments-card` — 文案:「PDF、作業附件放這。上傳時還能設「允許下載」跟 PDF 浮水印防盜課。」— 為何教:指出附件入口並預告防盜課設定。

**可中斷 / 備註:**

- 三個上傳元件(image/video/attachment-upload)的拖放區與設定只在各自子頁出現,總覽頁 DOM 沒有,故不直接錨在拖放區,改錨在通往該庫的常駐區塊卡(`media-videos-card` / `media-images-card` / `media-attachments-card`),文案對齊「點進去上傳」。框架會自動略過找不到的錨點。
- 統計卡與三張區塊卡為 `Suspense` 包裹的非同步內容,但外層容器(stats 容器 div、各 Card)首次載入即在 DOM,聚光燈可正常定位。
- 教學可隨時關閉;之後可點右上角問號重新開啟。
