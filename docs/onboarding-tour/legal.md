# 新手教學設計 — 隱私權政策 / 服務條款

> 路由:`/admin/privacy` 與 `/admin/terms` ｜ 對象:負責編輯法律條款的管理員(站長) ｜ 預估教學:約 30 秒(4 步)

這兩頁共用同一個編輯元件(`LegalMarkdownForm`),功能完全對稱,只差在編輯的是「隱私權政策」還是「服務條款」。因此共用同一組 `data-tour` 錨點,兩份教學文案各自貼合主題。

## 1. 頁面核心用途
讓站長用 Markdown 撰寫並儲存網站的法律條款。儲存後會直接顯示在前台對應頁面(`/privacy`、`/terms`),讓訪客與買家看得到。

## 2. 功能梳理(這頁能做什麼)
| 功能 | 使用者能做什麼 | 介面位置 | 教學優先級 |
|---|---|---|---|
| 頁面說明 | 知道改的內容會出現在前台哪個網址 | 頁首標題與說明文字 | ⭐ 必教 |
| 套用模板 | 一鍵生成通用法律範本,帶入站名與客服信箱 | 右上「套用模板」按鈕(開對話框) | ⭐ 必教 |
| 模板帶入欄位 | 在對話框輸入平台名稱、客服信箱代入文件 | 「套用模板」對話框內的兩個輸入框 | ◐ 可帶過(藏在對話框,錨到觸發按鈕帶過) |
| 覆寫確認 | 已有內容時套模板會跳出二次確認,防誤刪 | 套用時的瀏覽器確認框 | ✕ 不教(自然出現即可) |
| Markdown 編輯 | 自由撰寫、調整條款內容 | 中央 Milkdown 編輯器 | ⭐ 必教 |
| 儲存變更 | 把改動存檔並發佈到前台 | 底部浮動儲存列(有改動才出現) | ⭐ 必教 |

### 容易誤解 / 客戶常漏的點
- 以為改完就生效,其實**沒按儲存不算數**;儲存列只有在有改動時才浮出來,沒看到很容易漏。
- 以為「套用模板」只是參考,其實會**覆蓋掉現有內容**,且有內容時會先跳確認框。
- 範本只是起點,法律責任仍在站長身上,務必依自己情況增刪,別原封不動上線。

## 3. 新手教學流程
**開場白(隱私權):**
> 「這頁負責你網站的隱私權政策。改完存檔,訪客就能在 /privacy 看到。我帶你 30 秒上手。」

**開場白(服務條款):**
> 「這頁負責你網站的服務條款。改完存檔,買家就能在 /terms 看到。我帶你 30 秒上手。」

**逐步引導:**
1. **【這頁在做什麼】** — 特寫:`privacy-header` / `terms-header` — 文案:「你在這裡寫的內容,會直接顯示在前台給訪客看。」— 為何教:先讓人知道改動的影響範圍,避免亂改。
2. **【沒靈感?一鍵套範本】** — 特寫:`legal-template-btn` — 文案:「不知道怎麼寫?點這裡套通用範本,自動帶入你的站名。」— 為何教:法律條款最讓非法務頭痛,模板是最大省力點。(注:輸入站名/信箱的欄位在對話框內,點按鈕後才出現,故錨在按鈕)
3. **【在這裡自由編輯】** — 特寫:`legal-editor` — 文案:「條款內容在這裡編輯,支援 Markdown,排版隨你調。」— 為何教:這是頁面主體,讓人知道正文寫在哪。
4. **【記得按儲存才生效】** — 特寫:`legal-editor`(無專屬常駐錨點,沿用編輯器並提示) — 文案:「改完一定要存檔。底部會跳出儲存列,按下去才會發佈。」— 為何教:最常被漏掉、後果最直接,收尾強調。

**可中斷 / 備註:**
- 儲存列(`StickySaveBar`)只有在有未儲存變更時才 `fixed` 浮出、平時不在可視 DOM,無法穩定聚光燈,因此最後一步沿用 `legal-editor` 錨點,以文案口頭提示儲存列的存在與位置。
- `legal-editor`、`legal-template-btn` 由共用元件 `LegalMarkdownForm` / `LegalTemplateDialog` 提供,隱私與條款兩頁共用同一組錨點(同一時間只會掛載一頁,無衝突)。
- 頁首錨點各頁獨立:隱私為 `privacy-header`、條款為 `terms-header`。
- 框架會自動略過找不到的錨點,編輯器尚在載入(動態 import)時若錨點短暫不在,不影響其他步驟。
