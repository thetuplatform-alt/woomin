# 台灣電子發票（統一發票）啟用指南

> 這份指南是寫給「想在本平台販售線上課程、而且需要開立台灣統一發票」的營運者 / 老闆看的。
> 我們假設你**不是會計師、也沒開過公司、完全不熟發票流程**。讀完你會清楚知道三件事：
> 1. 你**有沒有資格**開發票（很多人卡在這一關）。
> 2. 要去**哪裡申請**、流程長怎樣、要花多久。
> 3. 拿到金鑰後，在**本平台後台**該填什麼。
>
> ⚠️ **本文為「操作流程說明」，不是稅務或法律意見。** 實際的稅務認定，請以你所在地**國稅局**與你的記帳士／會計師為準。文中標示「**待確認**」之處，請在申請時直接向加值中心業務或國稅局再次核對最新數字。

## 〇、30 秒自我檢測：我現在能不能開發票？

依序回答，遇到「否」就先停下來處理那一項：

1. 我（或我的事業）有沒有**統一編號（統編）**？
2. 我有沒有完成**營業登記 / 公司登記**，並在國稅局做了**稅籍登記**？
3. 我願不願意為了開發票，先把自己變成「**營業人**」（成立公司或行號）？

- **三題都是「有 / 願意」** → 你可以往下走完整流程。
- **只是個人接案、還沒成立公司** → 請先看下面「一、適用對象與前提」，你目前**還不能**開統一發票。

## 一、適用對象與前提（最重要，先決定你能不能往下做）

### ⛔ 前提：你必須是「有統編的營業人」，純個人無法開立統一發票

要開立台灣統一發票（電子發票），你**必須同時滿足以下三點，缺一不可**：

1. **是「營業人」** —— 已經過核准的**營業登記**（商業登記或公司登記）。
2. **有統一編號（統編）**。
3. **已在所在地國稅局完成「稅籍登記」**。

> 官方說法：開立統一發票者，必須是「**核准營業登記的營業人**」，並已向所在地主管稽徵機關（國稅局）完成**稅籍登記**。

### 個人（自然人）可以開統一發票嗎？

**原則上不行。** 純粹的個人 / 自然人，沒有營業登記與稅籍登記，**無法開立統一發票**。

要能開發票，你得先讓自己變成「營業人」，常見兩條路：

| 路徑 | 說明 | 要不要開發票 |
|------|------|--------------|
| **成立公司**（有限公司 / 股份有限公司） | 正式公司型態 | **一律要開**，沒有門檻 |
| **成立行號**（獨資 / 合夥，俗稱工作室、商行） | 較輕量的營業登記 | 達門檻才需要開（見下表） |

### 我到底要不要開發票？（門檻一覽）

| 你的身分 | 是否需要開統一發票 |
|----------|--------------------|
| **公司** | 一律要開，無門檻 |
| **行號（獨資 / 合夥）** | 月營業額超過約 **NT$200,000** 時才需開立統一發票（**待確認**，依國稅局實際核定為準）|
| **純個人 / 自然人** | 不能開統一發票。但若線上銷售達課稅門檻，須先辦稅籍登記、變成營業人 |

### ⚠️ 賣課程 = 銷售「勞務」，稅籍登記門檻比賣實體商品低

財政部規定（2025 年起的線上銷售認定）：

- 月銷售**勞務**（線上課程、軟體、服務屬此類）超過約 **NT$50,000**，或
- 月銷售**貨物**（實體商品）超過約 **NT$100,000**，

就**必須辦理稅籍登記、申報營業稅**。低於門檻可暫時免登記，但**一超過就要立刻補辦**。

> 重點：**課程的門檻（月 NT$50,000）比賣實體商品低**，很多人以為自己「還小、不用管」，其實早就超過了。數字請以國稅局公告為準（**待確認**）。

### 海外（外國）身分特別注意

即使你已定居台灣、持有**永久居留證**，外國身分通常**仍無法以個人名義**申請台灣金流 / 開立發票 —— 實務上多半需要**先在台灣設立公司**才能申請。這是金流商與加值中心的實務限制，請在申請前直接向對方再次確認（**待確認**）。

## 二、「加值中心」是什麼？為什麼你需要它？

「**加值中心**」（電子發票加值服務中心）= 財政部核准的第三方電子發票服務商。它幫你扛掉所有麻煩的系統工：

- 在法定時限內把發票資料**上傳到財政部平台**（B2C 須 48 小時內、B2B 須 7 天內）。
- 管理空白發票字軌號碼、自動配號。
- 處理每月例行作業、對獎、中獎通知等。

你**不需要自己開發、維護財政部的 Turnkey 系統**，把發票交給加值中心代開即可。

本平台目前內建串接 **綠界 ECPay** 與 **藍新 ezPay** 兩種發票加值中心（依你購買的版本而定）。三家關係速記：

| 服務商 | 它是什麼 | 與發票的關係 |
|--------|----------|--------------|
| **綠界 ECPay** | 金流商，同時自營電子發票加值中心 | 可直接申請發票，**本平台優先支援** |
| **藍新 ezPay** | 藍新金流（Newebpay）旗下的電子發票加值平台 | 可獨立申請、串接 |
| **PAYUNi 統一金流** | 金流商 | ⚠️ **PAYUNi 本身沒有「開發票」的 API**。用 PAYUNi 收款的商家，發票實務上是**透過 ezPay 開立**（見下方說明） |

> 🔑 **關鍵觀念：收款用哪家，和「發票用哪家」可以是兩件事。**
> 你可以用 PAYUNi 收信用卡、但用 ECPay 或 ezPay 開發票。本平台讓你**分開設定**金流與發票，互不綁定。

## 三、申請流程（兩家對照 Checklist）

> 兩家的骨架**完全一樣**：
> **先有營業人身分 → 申請發票字軌 → 授權加值中心配號（最關鍵）→ 後台設定 → 測試 → 上線。**
> 差別只在「去誰的後台操作、拿到哪幾把金鑰」。

---

### 🟢 綠界 ECPay 電子發票申請 Checklist（本平台優先支援，建議首選）

**前提（缺一不可）**
- [ ] 你是**中華民國境內的營利登記公司 / 行號**（營業人）。
- [ ] **沒有**積欠已確定的營業稅 / 營所稅及罰鍰。
- [ ] 已申請**工商憑證**（自然人憑證 / 工商憑證 IC 卡，授權配號時要用；申請約需 3–6 個工作天）。

**步驟**
1. [ ] **註冊綠界會員（商務帳號）**，提交開通文件：國稅局稅籍登記函 + 統編、綠界電子發票平台申請書、合約書、公司銀行帳戶 / 統編 / 登記地址 / 聯絡電話 / Email。
2. [ ] **提交字軌申請文件**：申請書、承諾書、系統自我檢測表、（如需紙本）熱感紙聲明書、**加值中心委任授權書**。
3. [ ] 與綠界專屬業務**確認服務方案並付款**。
4. [ ] **【最關鍵一步】到「財政部電子發票整合服務平台」做配號授權**（需插**工商憑證**登入）：
   - 把「營業人電子發票接收方式」設為 **加值中心**。
   - **取得字軌配號**（首次手動取號）。
   - **授權綠界**代為上傳空白字軌、自動配號。
   - ⚠️ 沒做這一步，後台金鑰填對也開不出發票。
5. [ ] **回綠界廠商後台做設定**：字軌配號設定、發票通知（Email / SMS）等。
6. [ ] **測試（Stage 測試環境）**：先用綠界提供的**公用測試參數**（MerchantID `2000132` 等）把流程跑通，確認能成功開出測試發票。
7. [ ] **上線（正式）**：換成你**自己公司**的正式 MerchantID / HashKey / HashIV，並**關閉測試模式**。

**綠界金鑰在哪拿**：綠界廠商後台 →「**系統設定 → 系統介接設定**」可取得 **MerchantID（商店代號）／ HashKey ／ HashIV**。

**費用（重點，數字為 2026 年參考值，請以官網最新報價為準）**
- 系統設定費（單次）：約 **NT$3,600**（續約戶通常 $0）。
- 新戶常有**期間限定優惠方案**（例如某段期間年度服務費 $0、附一定張數額度）—— 實際以申請當下官網公告為準（**待確認**）。
- 通知加購：Email 通知通常免費；簡訊通知約 NT$1.5 / 則。
- 以上多為**未稅價**，結算另加 5% 營業稅。

### 🟣 PAYUNi 收款的商家，發票怎麼開？（透過 ezPay）

> ⚠️ **先講清楚一件事：PAYUNi（統一金流）沒有「開立發票」的 API。**
> PAYUNi 是金流商，它能幫你**收款**，但它**不提供讓你開統一發票的介面**。用 PAYUNi 收款的商家，發票實務上是透過**藍新 ezPay**（或綠界 ECPay）這類加值中心開立。
>
> 所以如果你用 PAYUNi 收款，最直覺的做法是：**收款用 PAYUNi、發票用 ezPay**，兩邊分開申請、在本平台後台分開填。

#### ⚪ 藍新 ezPay 電子發票申請 Checklist

**前提**
- [ ] 你是**台灣營業人**（公司 / 行號）；外國身分需先在台設立公司。
- [ ] 已完成國稅局**稅籍登記**並取得**電子發票專屬字軌**（此為各加值中心共通前提）。
- [ ] 已申請**工商憑證**（授權配號用）。

**步驟**
1. [ ] **在 ezPay 平台建立帳號**（通常會有**測試帳號**與**正式帳號**兩套）。
2. [ ] **申請電子發票服務**，提交營業人相關文件。
3. [ ] **【最關鍵一步】到「財政部電子發票整合服務平台」授權配號**：把接收方式設為**加值中心（ezPay）**、取得字軌、授權代為配號與上傳空白字軌（需工商憑證）。
4. [ ] **在 ezPay 後台**：到「**發票管理 → 管理設定 → 發票字軌號碼設定**」，啟用「**委任設定**」與「**上傳空白未使用字軌**」。
5. [ ] **取得 API 串接金鑰**（商店代號 / HashKey / HashIV 等，欄位名稱以 ezPay 後台為準）。
6. [ ] **測試 → 正式**：先用測試帳號跑通，再切換正式金鑰、關閉測試模式。

**時程**：ezPay 官方說明整體作業約需 **12 個工作天起**（含買政府核可發票紙、申請字軌等）。

> 📌 如果你購買的本平台版本**尚未內建 ezPay 串接**，請告知你的工程師「我要串 ezPay 電子發票」，串接原則與 ECPay 相同（金鑰存 `SiteSetting`、付款成功後觸發開立），工作量不大。

進入後台「**金流收款 → 臺灣統一發票**」分頁，依你選的供應商填入對應欄位。

### 共用設定（不分供應商）

| 後台欄位 | 說明 |
|----------|------|
| **啟用電子發票** | 預設**關閉**。確認串接無誤前請保持關閉，避免開出錯誤發票 |
| **發票供應商** | 選 **綠界 ECPay** 或 **藍新 ezPay** |
| **賣方名稱** | 你公司 / 行號的抬頭名稱（會印在發票上） |
| **賣方統編** | 你的統一編號 |
| **測試模式** | 串接驗證階段請**開啟**；正式上線**務必關閉** |
| **付款成功後自動開立** | 開啟後，學員付款成功會**自動開立發票**；關閉則需到訂單頁手動開立 |

### 綠界 ECPay 憑證欄位

| 後台欄位 | 在哪裡拿 |
|----------|----------|
| **MerchantID（商店代號）** | 綠界廠商後台「系統設定 → 系統介接設定」 |
| **HashKey** | 同上 |
| **HashIV** | 同上 |

### 藍新 ezPay 憑證欄位

| 後台欄位 | 在哪裡拿 |
|----------|----------|
| **商店代號 / Merchant ID** | ezPay 後台「API 串接金鑰」區（欄位名稱以後台為準） |
| **HashKey** | 同上 |
| **HashIV** | 同上 |

> 🔒 **敏感欄位處理**：HashKey、HashIV 屬機密，後台**不會把已存的值顯示出來**，只會顯示遮蔽提示。若你只是要改其他設定、不想動金鑰，**這兩欄留空即可（留空 = 不變更）**。要更換金鑰時才重新輸入。

### ✅ 填完後一定要做的事

1. 按「**測試連線 / 開立測試發票**」按鈕，確認後台能成功連到供應商。
2. 確認測試發票能開出來、號碼正常。
3. **跑通測試 → 換成正式金鑰 → 關閉測試模式 → 才打開「啟用電子發票」。**
4. 千萬**別把測試金鑰留在正式站**，否則開出來的不是真發票。

---

### 測試金鑰 vs 正式金鑰（務必分清）

- **測試（Stage）金鑰**：只用於串接驗證，**不會產生真實發票、不會上傳財政部**。
  - 綠界有公用測試參數可直接用（例如 MerchantID `2000132`），API 走 `*-stage.ecpay.com.tw`。
- **正式金鑰**：你公司專屬，會**真的開出發票並上傳財政部**。
- **正確順序**：跑通測試 → 換正式金鑰 → 關測試模式 → 才正式開票。

## 五、課程 / 軟體賣家的稅務基礎（簡明版）

- **稅率**：課程屬「銷售勞務」，營業稅 **5%**。
- **定價含稅（內含）**：台灣 B2C 售價習慣**含稅**。例如標價 NT$1,499，內含稅額 ≈ 1,499 − (1,499 ÷ 1.05) ≈ **NT$71**，未稅銷售額 ≈ NT$1,428。後台填發票金額時注意這是「**含稅總額**」。
- **發票類型**：
  - **B2C（二聯式）**：賣給一般消費者（個人）。需選**載具**：手機條碼 / 自然人憑證 / 會員載具 / 捐贈碼 / 紙本。
  - **B2B（三聯式）**：買方是公司行號，需提供**買方統編 + 抬頭**，可作為對方的進項扣抵憑證。
- **載具實務**：B2C 最常見是「**手機條碼**」載具，消費者輸入 `/` 開頭的 8 碼條碼即可自動對獎；沒給載具就開紙本或會員載具。

## 七、常見問題（FAQ）

**Q1. 我是個人，可以開統一發票嗎？**
原則上**不行**。要先成為「營業人」（成立公司或行號 + 稅籍登記）才能開。純個人接案若月銷售勞務超過約 NT$50,000，本來就**該去辦稅籍登記**。

**Q2. 我還沒成立公司，可以先串接嗎？**
可以先用**測試金鑰**把串接跑通、確認功能正常，但**不能正式開票**。正式開票一定要等公司 / 字軌 / 加值中心授權都到位。

**Q3. 我用 PAYUNi 收款，那發票怎麼辦？**
PAYUNi 本身**沒有開發票的功能**。請另外申請 **ezPay（或綠界 ECPay）** 作為發票加值中心，在本平台後台把「收款」設 PAYUNi、「發票供應商」設 ezPay，兩者分開即可。

**Q4. 賣給海外客戶要開發票嗎？**
這牽涉「銷售地 / 勞務提供地」「外銷勞務是否適用零稅率」等認定，情況分歧，**請務必諮詢你的會計師 / 國稅局**（本文不下定論，**待確認**）。系統上你仍可逐筆決定是否開立、開立何種發票。

**Q5. 客戶結帳時要打統編怎麼辦？**
結帳時讓客戶填**買方統編 + 抬頭**，系統會開立 **B2B 三聯式**發票。沒填統編就開 **B2C 二聯式 + 載具**。

**Q6. 退款 / 退課要怎麼處理發票？**
通常**不是「作廢重開」**，而是開**折讓單**（銷貨退回、進貨退出或折讓證明單）來沖銷：
- 同期間、買方同意時，可在加值中心後台 / 本平台訂單頁對該張發票開立**折讓單**，把稅額一起退掉。
- 若已跨月、或發票已對獎中獎，處理方式不同，**依加值中心後台流程與會計師指示**操作。

**Q7. 測試金鑰可以一直用嗎？**
不行。測試金鑰只供開發驗證、不產生真實發票。正式上線**必須**換成你公司的正式金鑰並**關閉測試模式**，否則學員拿到的不是真發票。

**Q8. 我已經在用 ezPay 或其他加值中心，本平台支援嗎？**
本平台優先支援綠界 ECPay 與藍新 ezPay。若你用的是其他加值中心（如 Amego 等），請告知工程師，串接原則相同（金鑰存後台、付款後觸發開立），可另行擴充。
