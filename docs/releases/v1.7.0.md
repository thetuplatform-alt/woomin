# v1.7.0 版本更新說明

> 發布日期：2026-06-22
> 上一版本：v1.6.1

這一版是 1.6 之後最大的一次升級，重點圍繞在「**讓後台更好用**」與「**把台灣在地金流／稅務補齊**」兩條主線。除了肉眼可見的介面翻新與全站新手教學，底層也針對金流、發票與後台效能做了大量強化。

---

## 🎨 重點一：後台介面全面重新設計

舊版後台介面相當老氣，這次不只是視覺美術的調整，更針對使用者體驗（UX）中**不直覺、不直觀、對老師不友善**的環節做了系統性優化，大大小小總計數十項 UI 重新設計。

幾個最有感的改動：

- **更清楚的「新增老師與管理員」流程**：新增了獨立的「講師管理」頁面（側邊欄「系統與法律」群組，僅管理員可見）。新增成員時可用 **Email 即時搜尋**——輸入關鍵字就會即時列出符合的既有用戶，點選後一鍵把對方設為講師或管理員；查無此人時則直接新建帳號，整個流程不再需要猜測該去哪裡操作。
- **更明確的金流設定與建立流程**：把「金流」從綜合設定頁獨立成專屬頁面 `/admin/payments`，內含「金流收款」與「臺灣統一發票」兩個分頁，設定與切換金流的操作路徑更清楚。
- **學員管理頁重塑**：原「用戶管理」正名為「學員管理」，新增**依課程篩選**、新增／匯入學員時可**指派多門課程並自選是否寄送邀請信**，操作欄也從單一 icon 改為清楚的文字按鈕。
- **動態圖示與載入體驗**：後台改用動態圖示（Lordicon），並為主要頁面加上載入骨架，畫面切換更流暢、不再空白卡頓。

---

## 🧭 重點二：全新「新手教學」功能

後台**每一個頁面、每一個功能**都加上了新手教學。在後台每個頁面的**右上角都有一顆問號按鈕**，按下去就會啟動該頁面的逐步導覽，手把手帶你認識每個區塊在做什麼。

- 涵蓋儀表板、課程列表／新增／資訊／定價／內容／作業／留言／私訊／評價／分析、媒體中心、學員管理、講師管理、訂單、優惠券、組合包、金流、發票、系統設定、隱私權與服務條款等全部後台頁面。
- 第一次進站、或不確定某個功能怎麼用時，隨時可以打開該頁教學，不必再去翻文件。

---

## 💬 重點三：老師通訊功能優化

針對老師端的通訊功能做了重新設計，提升直覺性與整體使用體驗：

- **「課程留言」與「老師私訊」徹底拆分**：前台播放頁、後台側邊欄、課程編輯頁三個地方，原本混在一起的「評論」都拆成兩個各自獨立的入口——群組留言歸群組留言、一對一私訊歸私訊，互不干擾。
- **Messenger 式對話收件匣**：老師端私訊從過去的「扁平大表」改造成**依學員聚合的對話收件匣**，支援未讀紅點與未讀數 badge、最後訊息預覽、行內回覆（不必再開彈窗）、附件，以及「待回覆」篩選。
- **老師可查看學員測驗結果**（新功能）：後台過去無法檢視學員的測驗作答，這版補齊了完整的測驗結果頁——全班成績總覽、通過率與平均分統計、逐題作答 vs 正解對照、多次作答紀錄，並支援 **CSV 匯出**。

## 🧾 重點四：臺灣統一發票功能正式推出

台灣的老師現在可以自由選擇使用 **「綠界 ECPay」** 或 **「藍新 ezPay」** 來串接並自動／手動開立電子發票。

- **可選、預設關閉**：未啟用時平台行為與過去完全相同（不收發票資訊、不開發票），符合平台「上線後再啟用」的一貫設計。
- **後台自助設定**：在 `/admin/payments` →「臺灣統一發票」分頁，填入加值中心憑證（MerchantID／HashKey／HashIV）與賣方資訊即可啟用，並提供「測試連線／試開發票」按鈕先驗證串接是否正確。
- **結帳收集發票資訊**：啟用後，學員結帳時可選擇「個人（手機條碼／雲端載具）」「公司（統編＋抬頭）」「捐贈（愛心碼）」。
- **完整的發票生命週期**：支援付款成功後**自動開立**（亦可關閉改手動），以及在訂單詳情頁進行**作廢**與**折讓**（退款沖銷），並以資料庫層級唯一約束保證「同一張訂單只會開立一次」。
- **與金流解耦**：發票供應商與收款金流各自獨立設定——即使用 PAYUNi 收款（其本身無發票 API），仍可透過 ECPay／ezPay 開立發票。

> 啟用步驟詳見後台「臺灣統一發票」分頁內的「閱讀申請指南」連結，或專案 `docs/台灣電子發票啟用指南.md`。

## 👥 重點五：多講師權限系統

講師從過去「課程上的一段自訂文字」，正式升級為**平台角色**，讓平台能支援多位講師協作，同時把平台級的敏感功能保護好。

- 新增 `INSTRUCTOR`（講師）角色；舊有 `EDITOR` 自動相容視為講師，既有資料不受影響。
- 講師可建立課程、管理自己有權限的課程；管理員可在課程資訊頁指定**哪些講師能管理哪門課**（未指定時為全部講師）。
- 課程、留言、私訊、優惠券、測驗結果等全面套用**後端課程隔離**——講師看不到也動不了非自己授權課程的資料，即使手動改網址也擋得住。
- 講師**看不到**銷售分析、系統設定、隱私權政策、服務條款、組合包等平台級功能；所有角色管理操作僅限管理員，並完整記錄到操作日誌（AdminLog）。

## ⚡ 重點六：效能優化

修正了後台會卡頓的問題：

- 針對儀表板與分析常見的聚合查詢（全站營收／本月／趨勢／Top 課程、學員列表、每日活躍與學習人數等）**新增多個資料庫索引**，大幅降低大量訂單／學員資料下的查詢延遲。
- 儀表板不再因為 PostHog 漏斗資料而被卡住載入。
- 後台主要頁面加上載入狀態，切頁不再空白。
- Docker／Zeabur 部署改為 `output: "standalone"`，建置產物更精簡。

---

## 🔒 金流與發票安全性、可靠性強化

本版同步進行了一輪金流＋電子發票的安全稽核並修復多項缺陷，讓真實營運情境（ATM／超商付款、組合包與單課重疊購買後退款、後台帶外退款、發票開立／作廢／折讓等）更穩健、不掉錢也不掉權限。涵蓋退款狀態機一致性、金額完整性驗證、發票開立冪等與失敗重試、優惠券兌換競態防護等。

> 細節稽核報告見 `docs/audits/payment-invoice-audit-2026-06-22.md`。

## 🐛 其他修正與改進

- **組合包購買確認信修正**：修正組合包訂單只寄出第一門課程通知信的問題，現在每門課各自獨立寄送一次（信件冪等鍵改為 `type + orderId + courseId`）。
- **PDF 上傳**：新增動態浮水印與下載選項控制。
- **優惠券兌換冪等**：同一張訂單只會記錄一次兌換（webhook 重送／重複處理時的兜底）。

## ⚙️ 升級注意事項

這版有**新增的套件依賴**與**資料庫結構變更**，升級時請務必完成：

1. **安裝新依賴**：`pnpm install`
   - 新增：`@paid-tw/einvoice`、`@paid-tw/einvoice-ecpay`、`@paid-tw/einvoice-ezpay`（電子發票）、`@lordicon/react`、`lottie-web`（後台動態圖示）。
2. **套用資料庫遷移**：`pnpm prisma migrate deploy`（或 `pnpm prisma db push`）
   - 本版含 6 個 migration：新增講師角色與課程授權表、臺灣電子發票資料表、優惠券／留言／管理操作日誌類型、Prisma 7 schema 對齊、安全稽核修正、效能索引。
3. **環境變數**：**無新增**——電子發票憑證等敏感設定一律存於後台（SiteSetting），不需改 `.env`。

> 透過 `/upgrade-platform` 自動升級時，上述安裝與遷移會在流程中處理；手動部署請依上面步驟操作。

### 結構變更摘要（schema）

- 新增 `INSTRUCTOR` 角色（`EDITOR` 相容視為講師）。
- 新增 `CourseInstructor`（課程↔講師授權）、`Course.createdById`（課程建立者）。
- 新增 `Invoice` model 與 `InvoiceStatus`／`InvoiceType` enum；`Order` 新增買受人發票偏好欄位。
- `EmailDeliveryLog` 唯一鍵由 `[type, orderId]` 改為 `[type, orderId, courseId]`；`CouponRedemption` 新增 `[orderId]` 唯一鍵。
- 新增多個效能索引（`User`、`Order`、`Course`、`WatchTimeLog` 等）。
- `AdminAction` enum 新增發票、優惠券、留言刪除等操作類型。

升級流程會自動套用以上變更，**既有資料相容、無破壞性 API 變更**。
