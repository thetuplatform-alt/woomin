# 課程 Dashboard 重構 — BDD 規格

## 概述
課程編輯 Dashboard（`/admin/courses/[id]/`）目前將 27 個表單欄位全部塞在「課程資訊」單一 tab 中，且 tab 分類不符合使用頻率。此重構將 tab 重新分為 5 個，將定價獨立成 tab，並為「課程資訊」頁面（含行銷設定）加入 Ghost 風格的左側導覽，讓講師能快速定位要修改的區塊。

## 行為規格

### 場景 1：Tab 導覽重新分類
**Given** 管理員進入課程編輯頁面 `/admin/courses/[id]/info`
**When** 查看頂部 Tab 導覽
**Then** 看到 5 個 tab，依序為：課程資訊、定價與促銷、課程內容、留言、分析

### 場景 2：課程資訊頁 — 左側導覽
**Given** 管理員在「課程資訊」tab
**When** 頁面載入
**Then** 左側顯示固定的導覽側邊欄，列出所有可設定區塊（基本資訊、封面圖片、講師資訊、課程狀態、SEO 設定、OG / Social、銷售頁設定、通知設定）
**And** 右側顯示對應的表單卡片，按導覽順序排列

### 場景 3：課程資訊頁 — 點擊導覽捲動
**Given** 管理員在「課程資訊」tab，左側導覽可見
**When** 點擊左側導覽的某個項目（例如「SEO 設定」）
**Then** 右側表單 smooth scroll 到對應的卡片區塊

### 場景 4：課程資訊頁 — 滾動時高亮追蹤
**Given** 管理員在「課程資訊」tab
**When** 滾動右側表單內容
**Then** 左側導覽自動高亮當前可見區塊對應的項目（使用 IntersectionObserver）

### 場景 5：課程資訊頁 — 欄位分配
**Given** 管理員在「課程資訊」tab
**When** 查看表單內容
**Then** 包含以下區塊：基本資訊（標題、副標題、Slug、描述）、封面圖片、講師資訊、課程狀態、SEO 設定、OG/Social、銷售頁設定、通知設定
**And** 不包含定價相關欄位

### 場景 6：定價與促銷頁 — 獨立 tab
**Given** 管理員點擊「定價與促銷」tab
**When** 頁面載入
**Then** 顯示定價相關的所有欄位：原價、促銷價、促銷說明文字、永久優惠開關、顯示倒數時鐘、循環天數、促銷截止日期
**And** 保留原有的條件渲染邏輯（永久優惠 on/off 影響子欄位顯示）
**And** 有獨立的儲存按鈕

### 場景 7：通知設定區塊
**Given** 管理員在「課程資訊」tab 的通知設定區塊
**When** 查看內容
**Then** 包含「購買成功 Email 通知」開關（notifyAdminOnPurchase）
**And** 包含一個前往「歡迎信設定」的連結，點擊導向 `/admin/courses/[id]/welcome-email`

### 場景 8：歡迎信頁面保留但隱藏 tab
**Given** 管理員透過通知設定的連結進入歡迎信設定頁
**When** 頁面載入
**Then** 歡迎信編輯頁面功能完全不變（Milkdown 編輯器、關鍵字、預覽、測試寄送）
**And** 頂部 tab 導覽中「課程資訊」tab 處於 active 狀態

### 場景 9：表單儲存行為
**Given** 管理員在任一個有表單的 tab（課程資訊、定價與促銷）
**When** 修改欄位後點擊儲存
**Then** 僅儲存該 tab 的欄位，不影響其他 tab 的資料
**And** 顯示成功或失敗的 toast 通知

### 場景 10：響應式 — 小螢幕隱藏側邊導覽
**Given** 管理員在手機或窄螢幕瀏覽「課程資訊」頁面
**When** 螢幕寬度小於 lg breakpoint
**Then** 左側導覽隱藏，表單佔滿全寬
**And** 表單功能不受影響

## Acceptance Criteria
- [ ] AC-01：Tab 導覽顯示 5 個 tab：課程資訊、定價與促銷、課程內容、留言、分析
- [ ] AC-02：課程資訊頁左側有固定導覽側邊欄，列出 8 個區塊（基本資訊、封面圖片、講師資訊、課程狀態、SEO 設定、OG / Social、銷售頁設定、通知設定）
- [ ] AC-03：點擊左側導覽項目時，右側表單 smooth scroll 到對應區塊
- [ ] AC-04：滾動右側表單時，左側導覽自動高亮當前可見區塊（IntersectionObserver）
- [ ] AC-05：課程資訊頁包含基本資訊 + 行銷設定的所有欄位，不含定價欄位
- [ ] AC-06：定價與促銷為獨立 tab，包含原價、促銷價、促銷說明、永久優惠、倒數時鐘、循環天數、截止日期，條件渲染邏輯不變
- [ ] AC-07：定價與促銷頁有獨立的儲存按鈕，僅儲存定價相關欄位
- [ ] AC-08：通知設定區塊包含 notifyAdminOnPurchase 開關和前往歡迎信設定的連結
- [ ] AC-09：歡迎信頁面功能不變，但進入時頂部 tab 的「課程資訊」處於 active 狀態
- [ ] AC-10：小螢幕（< lg）時側邊導覽隱藏，表單佔滿全寬
- [ ] AC-11：各 tab 的儲存操作互不影響，僅儲存該頁面的欄位
- [ ] AC-12：Next.js build 通過，無 TypeScript 錯誤

## 排除範圍（Out of Scope）
- 不改動課程內容（content）tab 的功能
- 不改動留言（comments）tab 的功能
- 不改動分析（analytics）tab 的功能
- 不新增任何資料庫欄位或 API
- 不改動 Zod 驗證 schema 的驗證規則本身（但需為分頁表單建立子 schema）
- 不改動歡迎信表單元件的內部功能
